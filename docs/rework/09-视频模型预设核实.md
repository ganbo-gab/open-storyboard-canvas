## 2. Seedance：火山方舟 / BytePlus ModelArk

### 2.1 模型与参数

来源 [S1][S2][S3][S4]，均于 **2026-10-23** 读取。两个地区的当前能力表一致，模型 ID 与基础域名不同。

| 模型 | 火山方舟精确 ID | BytePlus 精确 ID | 分辨率 `resolution` | `duration`（整数秒） | 全能参考数量 |
|---|---|---|---|---|---|
| 2.5 | `doubao-seedance-2-5-260628` | `dreamina-seedance-2-5-260628` | `480p / 720p / 1080p`，默认 `720p` | `4–30` 或 `-1`；默认 `-1` | 图 ≤30、视频 ≤10、音频 ≤10 |
| 2.0 | `doubao-seedance-2-0-260128` | `dreamina-seedance-2-0-260128` | `480p / 720p / 1080p / 4k`，默认 `720p` | `4–15` 或 `-1`；预设默认 5 | 图 ≤9、视频 ≤3、音频 ≤3 |
| 2.0 Fast | `doubao-seedance-2-0-fast-260128` | `dreamina-seedance-2-0-fast-260128` | `480p / 720p`，默认 `720p` | `4–15` 或 `-1`；默认 5 | 同 2.0 |
| 2.0 Mini | `doubao-seedance-2-0-mini-260615` | `dreamina-seedance-2-0-mini-260615` | `480p / 720p`，默认 `720p` | `4–15` 或 `-1`；默认 5 | 同 2.0 |

`4k` 必须小写；2.5 的 `1080p` 与 2.0 的 `4k` 使用 10bit H.265/HEVC，播放兼容性不能等同于普通 8bit H.264。

| 模式（上述模型，除特殊标注外） | 精确输入形式 | 比例、时长与限制 | 预设模式 |
|---|---|---|---|
| 文生视频 | `content:[{type:"text",text:…}]` | `ratio` 支持 `adaptive / 16:9 / 4:3 / 1:1 / 3:4 / 9:16 / 21:9` | `text-to-video` |
| 首帧 | 图片项 `type:"image_url"`，`image_url:{url:…}`，`role:"first_frame"` | 恰好 1 图；2.5 仅 `adaptive`，2.0 可指定比例 | `first-frame` |
| 首尾帧 | 2 个图片项，角色分别 `first_frame`、`last_frame` | 两图各 1；2.5 仅 `adaptive`；尾帧可能按首帧比例裁剪 | `first-last-frame` |
| 全能参考：图片起步 | 图片 `role:"reference_image"`，可加入 `reference_video` / `reference_audio` | 至少 1 图；其余类型可选 | `reference-images` |
| 全能参考：视频起步 | `type:"video_url"`，`video_url:{url:…}`，`role:"reference_video"` | 至少 1 视频；其余类型可选；2.0 也可通过提示词表达编辑/延长意图 | `reference-video` |
| 全能参考：音频起步（仅 2.5） | `type:"audio_url"`，`audio_url:{url:…}`，`role:"reference_audio"` | 允许纯音频输入；2.0 音频必须搭配图片或视频 | `reference-audio` |
| 视频编辑（2.5） | 参考视频 + `omni_reference_task_type:"edit"` | 必须 `ratio:"adaptive"`、`duration:-1`；输入视频 4–30 秒 | `video-edit` |
| 视频延长（2.5） | 参考视频 + `omni_reference_task_type:"extend"` | 必须 `ratio:"adaptive"`；提示词指明向前/向后延长对象 | `video-extend` |

2.5 的普通参考模式发送 `omni_reference_task_type:"reference"`。该字段仅 2.5 声明，**2.0 不发送**。显式任务类型能提前检查约束，但模型仍会判断提示词意图；不匹配可异步失败，不能承诺参数值会强制覆盖提示词。

严格首帧、严格首尾帧、全能参考三者互斥。全能参考中的图片即使被提示词指定为“首帧”，也不等于严格 `first_frame` 约束。

### 2.2 共同参数与素材限制

来源 [S1][S3]，读取日期 **2026-10-23**。

| 参数 / 限制 | 已核实值与预设处理 |
|---|---|
| `generate_audio` | 布尔，默认 `true`；生成同步声音，关闭则无声；输出声音为单声道 |
| `watermark` | 布尔，默认 `false` |
| `return_last_frame` | 布尔，默认 `false`；开启后同时解析 `content.last_frame_url` 为图片资产 |
| `output_format` | 仅 2.5：`mp4 / mov`，默认 `mp4`；专业 MOV 部分播放器不兼容 |
| `priority` | 整数 `0–9`；不填交给上游默认 0；只影响同一 Endpoint 排队顺序 |
| `execution_expires_after` | 整数 `3600–259200` 秒，上游默认 `172800`；不与本地轮询等待时长混淆 |
| `seed / camera_fixed / frames` | 当前模型级支持名单未列 2.0/2.5；**不发送**。API 顶层出现这些字段不代表每个模型都支持 |
| `fps` | 没有本轮模型可调整的请求字段；`framespersecond` 是查询响应字段，不当作入参 |
| 图片 | 单图 <30MB、每边 300–6000px、宽高比 0.4–2.5；JPEG/PNG/WEBP/BMP/TIFF/GIF，当前系列还支持 HEIC/HEIF |
| 视频 | MP4/MOV，单个 ≤200MB、24–60fps、每边 300–6000px、宽高比 0.4–2.5；总像素 407696–8295044 |
| 视频 / 音频时长 | 2.0：每段 2–15秒、各类型总时长 ≤15秒；2.5：每段 2–30秒、各类型总时长 ≤30秒，编辑视频最短 4秒 |
| 音频 | WAV/MP3，单个 ≤15MB；请求体 ≤64MB |
| 人脸 | 直接上传含真人人脸参考素材受限；须遵守授权人物素材、平台可信原始产物等规则，不能只看文件扩展名认定可用 |

预设选用公网素材 URL，避免将大视频 Base64 塞入请求；上游也支持部分素材 ID 和图/音频 data URI。素材上传、人物授权、Draft 样片→正式成片、web_search 工具与回调属于额外工作流/功能，不在本轮自动执行范围，不伪装成普通参考槽位。

### 2.3 HTTP 与轮询

- 国内 `baseUrl`: `https://ark.cn-beijing.volces.com`；国际：`https://ark.ap-southeast.bytepluses.com`。
- 鉴权均为 `Authorization: Bearer <key>`。
- 创建：`POST /api/v3/contents/generations/tasks`，JSON；返回 `{ "id": "…" }`。
- 查询：`GET /api/v3/contents/generations/tasks/{id}`。
- 状态字段 `status`：`queued / running / succeeded / failed / cancelled / expired`。
- 成功输出 `content.video_url`；可选尾帧 `content.last_frame_url`；错误 `error.message`。
- 任务保留 7 天，输出链接有效 24 小时；2.5 输出链接最多下载 100 次。
- 预设每 10 秒查询、本地最多等待 30 分钟；这是客户端策略，不是新增上游参数。超时后只能查询同一任务或用户明确重提。

查询证据 [S5]，读取日期 **2026-10-23**。

## 3. MiniMax H3 与海螺

### 3.1 H3 / H3 Max（V2）

来源 [M1][M2][M3][M4]，均于 **2026-10-23** 读取。

| 精确模型 ID | 文生 / 首帧 / 首尾帧 | 全能参考 | `resolution` | `duration` | 特有参数 |
|---|---|---|---|---|---|
| `MiniMax-H3` | 已声明 | 图片、视频、音频任意组合 | `768P / 2K` | 任意整数 `4–15` | 无已声明 `seed / fps / camera_fixed / generate_audio` 控件 |
| `MiniMax-H3-Max` | 已声明 | 详细 API 明确支持，但模型概览有冲突 | `480P / 768P`，**不支持 2K** | 任意整数 `5–15`，**不支持 4秒** | `extra.prompt_expansion_mode`: `disabled / balanced / quality`，默认 `balanced` |

每次请求均须包含非空文本项，每项 ≤7000 字符；`model / content / resolution / duration` 必填。预设选择 `768P`、5 秒作为初始配置，不声称 H3 的全部必填字段有服务端默认值。

| 模式 | 请求形状与比例规则 | 槽位 |
|---|---|---|
| 文生 | `content` 仅文本；`ratio` 必填且不能 `adaptive`，支持六种具体比例 | 无 |
| 首帧 | 图片 `role:"first_frame"`；`ratio:"adaptive"` | 首帧 1 |
| 首尾帧 | 图片分别 `first_frame / last_frame`；`ratio:"adaptive"` | 各 1 |
| 多模态参考 | 图/视频/音频对象与 Seedance 相同嵌套 URL 形状，角色 `reference_image / reference_video / reference_audio`；`ratio` 可为 `adaptive` 或六种具体比例 | 图 ≤9、视频 ≤3、音频 ≤3 |

全能参考分为图片、视频、音频起步三个入口，至少一种对应素材必填；没有将“任意一种至少 1”错误实现为“每种都必须有”。严格首尾帧与参考角色不可混用。**混合素材总数 ≤12**，数量上限不能理解为可以同时提交 9+3+3。

| 素材 | 限制 |
|---|---|
| 图片 | JPG/JPEG/PNG/WEBP/HEIC/HEIF；≤30MB；每边 256–5760px；宽高比 0.4–2.5 |
| 视频 | ≤3段，MP4/MOV，H.264/H.265，23.976–60fps；单段 2–15秒、总时长 ≤15秒；单个 ≤50MB；尺寸/比例同图片 |
| 音频 | ≤3段，WAV/MP3；单段 2–15秒、总时长 ≤15秒；单个 ≤15MB |
| 整体 | 请求体 ≤64MB；也支持 `mm_file://{file_id}`，预设不自动执行上传；上传输入文件有效 7天 |

不确定性保留：

1. H3 Max 参考模式依据详细 API/OpenAPI 与生成指南实施，不能把冲突的概览当成它完全不支持参考的结论。
2. 文档 `content` 组合和指南允许“仅尾帧”，但 `ContentItem.role` 又说 `last_frame` 必须搭配首帧；**不注册单尾帧模式**。
3. 国际 H3 文档未声明 `aigc_watermark`；国内 [M3] 明确声明，所以仅国内 H3 模板发该字段。两地区不共享一个悄悄增字段的模板。
4. 没有足够官方证据将 H3 多模态参考等同于专用视频编辑/延长端点，不凭其他厂商能力类推。

### 3.2 Hailuo V1 仍可用的当前模型

来源 [M5][M6][M7][M8]，读取日期 **2026-10-23**。

| 精确模型 ID | 模式 | 官方时长 / 分辨率组合 | 参考上限 |
|---|---|---|---|
| `MiniMax-Hailuo-2.3` | 文生、首帧 | 6秒 `768P / 1080P`；10秒仅 `768P` | 首帧 1 |
| `MiniMax-Hailuo-2.3-Fast` | **仅首帧** | 同上 | 首帧 1 |
| `MiniMax-Hailuo-02` | 文生、首尾帧 | 6秒 `768P / 1080P`；10秒仅 `768P` | 无或首尾各 1 |
| `MiniMax-Hailuo-02` | 首帧 | 6秒 `512P / 768P / 1080P`；10秒 `512P / 768P` | 首帧 1 |

时长与分辨率以一个对象型枚举 `output` 显示“6秒 · 1080P”等有效组合，再由模板分别读取 `.duration / .resolution`；不是两个随意组合的枚举。故不可能在本预设中选出 10秒+1080P。

- `prompt_optimizer`: 布尔，默认 `true`。
- `fast_pretreatment`: 布尔，默认 `false`，仅文生/首帧 API 声明；**首尾帧不发送**。
- 提示词 ≤2000 字符；图 JPG/JPEG/PNG/WEBP，<20MB、短边 >300px、宽高比 0.4–2.5。
- 首尾帧仅 `MiniMax-Hailuo-02` 声明，不把 2.3 首帧能力扩写为首尾帧。
- 旧 `S2V-01` 只声明单人物单图参考，未出现在当前可用模型目录；不借它为 Hailuo2.3 生成虚构参考模式。

### 3.3 区域、异步协议与下载

| 项目 | H3 V2 | Hailuo V1 |
|---|---|---|
| 国际 / 国内基础地址 | `https://api.minimax.io` / `https://api.minimax.cn` | 同左；不是凭记忆沿用旧 `api.minimaxi.com` |
| 鉴权 | Bearer API Key | Bearer API Key |
| 创建 | `POST /v2/video_generation` | `POST /v1/video_generation` |
| 提交任务 ID | `task_id` | `task_id` |
| 查询 | `GET /v2/query/video_generation/{task_id}` | `GET /v1/query/video_generation?task_id={task_id}` |
| 状态字段 | `task.status` | `status` |
| 等待状态 | `queued / running` | `Preparing / Queueing / Processing` |
| 成功 / 失败 | `succeeded` / `failed, cancelled` | `Success` / `Fail`（大小写精确） |
| 结果 | 查询直接返回 `task.content.url` | 成功查询只返回 `file_id`，不是视频 URL |
| 额外结果查询 | 无 | `GET /v1/files/retrieve?file_id={file_id}`，读取 `file.download_url` |
| 错误 | 任务 `task.error.message`；HTTP 错误可能为顶层 `error` | `base_resp.status_msg` |

证据 [M9][M10]，读取日期 **2026-10-23**。注意 V1 回调的 `processing / success / failed` 小写与 GET 查询状态不同，不混用。

## 4. 通义万相 Wan3.0

来源 [W1][W2][W3]，读取日期 **2026-10-23**；英文 API 页面更新于 2026-10-15，明确标注 Preview。

| 模型 ID | 定位 | 模式 | 输出参数 / 限制 |
|---|---|---|---|
| `wan3.0-video` | 标准版 | 文生、首帧、首尾帧、图/视频/音频全能参考、编辑、延长 | `resolution`: `480P / 720P / 1080P`，默认 `1080P`；30fps，无可调 fps 入参 |
| `wan3.0-video-prime` | 高速版，能力对齐标准版 | 同上 | 同上 |

统一创建接口：

```text
POST https://{WorkspaceId}.{RegionId}.maas.aliyuncs.com/api/v1/services/aigc/video-generation/video-synthesis
Authorization: Bearer <API_KEY>
X-DashScope-Async: enable
Content-Type: application/json
```

**必须填入真实工作空间域名。** `wanVideoProfile.baseUrl` 中 `your-workspace-id` 是配置位置示例，不是可用账号或兜底服务；保存使用前替换。模型、Key、工作空间、地域须一致。官方列出北京 `cn-beijing`、新加坡 `ap-southeast-1`、弗吉尼亚 `us-east-1`、东京 `ap-northeast-1`、法兰克福 `eu-central-1`、香港 `cn-hongkong`。

请求：

```json
{
  "model": "wan3.0-video",
  "input": {
    "prompt": "将 Video 1 中的杯子改成红色",
    "media": [{ "type": "reference_video", "url": "https://assets.example/video.mp4" }]
  },
  "parameters": {
    "resolution": "1080P", "ratio": "adaptive", "duration": -1,
    "audio": true, "prompt_extend": true, "watermark": false
  }
}
```

该示例只说明文档形状，URL 为说明性素材地址，不是执行过的请求。

| 模式 | `input.media` | 约束 |
|---|---|---|
| 文生 | 省略，不发送空占位素材 | `input.prompt` |
| 首帧 | `{type:"first_frame",url:…}` | 1图；禁止混入任何参考音频、参考视频或参考图 |
| 首尾帧 | `first_frame`、`last_frame` 各一项 | 各1；同样与参考素材互斥 |
| 图/视频/音频参考 | `reference_image / reference_video / reference_audio` 类型对象 | 图≤10、视频≤5、音频≤5，素材共≤20；按类型分别编号 Image 1 / Video 1 / Audio 1 |
| 编辑 | 参考视频 + 编辑提示词 | 无独立 task_type 字段；官方推荐 `ratio:adaptive`、`duration:-1` |
| 延长 | 参考视频 + 明确向前/向后延长的提示词 | 官方推荐 `ratio:adaptive`；不伪造独立延长端点 |

| 参数 / 素材 | 已核实规则 |
|---|---|
| `duration` | 默认5；无视频输入时整数2–30或-1；有视频时，**输入视频总时长+输出时长≤30秒** |
| `ratio` | `adaptive / 21:9 / 16:9 / 4:3 / 1:1 / 3:4 / 9:16`，默认 `adaptive` |
| `audio` | 布尔，默认 `true`；控制输出音轨，不是 `generate_audio` |
| `prompt_extend` | 布尔，默认 `true`；智能改写，增加延迟 |
| `watermark` | 布尔，默认 `false` |
| `seed` | 整数-1或0–2147483647；-1/省略表示随机，不保证完全复现 |
| 提示词 | `prompt` 与 `media` 至少一项；文本≤20000字符 |
| 图片 | ≤20MB，JPEG/JPG/PNG（无透明通道）/BMP/WEBP，每边240–8000px，宽高比1:8–8:1 |
| 视频 | MP4/MOV，单个≤100MB、1–15秒，所有视频共≤15秒，≥16fps，每边240–4096px，宽高比1:8–8:1 |
| 音频 | WAV/MP3，单个≤15MB、1–15秒，所有音频共≤15秒 |
| 文件/网页 | 官方另外支持 `file` / `link` 各最多1，二者互斥且须 `prompt_extend:true`；不属于当前图/视频/音频槽位，不在预设中冒充媒体引用 |

**禁止继承旧版字段**：Wan3 预设不发 `size / negative_prompt / shot_type / generate_audio`。Wan2.6 文生/参考视频的 `size`（例如 `1920*1080`）和旧首尾帧 `/image2video/` 路径都不是 Wan3 的协议。

提交返回 `output.task_id`；同一工作空间地址 `GET /api/v1/tasks/{task_id}`。状态 `output.task_status`：`PENDING / RUNNING / SUCCEEDED / FAILED / CANCELED / UNKNOWN`。预设成功只认 `SUCCEEDED`，后三种作为终止失败；结果 `output.video_url`，错误 `output.message`。任务 ID 与链接24小时有效。每15秒查询、本地等待30分钟，不自动重复创建任务。

## 5. Vidu Q3

来源 [V1][V2][V3][V4][V5]，读取日期 **2026-10-23**。优先采用当前分类目录中的模型专属页面，不采用旧 `/docs/text-to-video` 页面残留的 Q1 样例。

| 模型 ID | 预设模式 | `duration` | `resolution` | 参考限制 |
|---|---|---|---|---|
| `viduq3-pro` | 文生、首帧、首尾帧 | 整数1–16，默认5 | `540p / 720p / 1080p`，默认 `720p` | 首帧1，首尾各1 |
| `viduq3-turbo` | 文生、首帧、首尾帧 | 整数1–16，默认5 | 同上 | 同上；主体参考接口另见下述边界 |
| `viduq3-pro-fast` | 首帧、首尾帧 | 整数1–16，默认5 | `720p / 1080p`，默认 `720p` | 同上 |
| `viduq3` | 普通多图参考 | 整数3–16，默认5 | `540p / 720p / 1080p`，默认 `720p` | 1–7张普通参考图 |

- 基础地址 `https://api.vidu.com`，鉴权 **`Authorization: Token <key>`**，不是 Bearer。
- 文生：`POST /ent/v2/text2video`；首帧：`POST /ent/v2/img2video`；首尾：`POST /ent/v2/start-end2video`；参考：`POST /ent/v2/reference2video`。
- 图生和普通多图参考使用 `images:[url,…]`；首尾固定按槽位写首帧在前，不按用户素材插入顺序猜测。
- `audio` 默认 `true`；`seed` 省略或0为随机；文生 `aspect_ratio` 支持 `16:9 / 9:16 / 3:4 / 4:3 / 1:1`；普通参考还声明 `auto`，预设采用其中已核实的五种固定画幅。
- 首帧可设置 `is_rec`；预设为 `false`，避免上游推荐词覆盖用户填写的提示词。
- PNG/JPEG/JPG/WEBP，宽高比1:4–4:1，单图≤50MB、Base64解码后<10MB；首尾像素面积比0.8–1.25；普通多图参考图片至少128×128、请求体≤20MB。
- Q3 Pro 提示词≤20000字符；Turbo 文生和普通Q3参考≤5000字符；图生/首尾页≤20000字符。
- Q3输出24fps；未声明可调 fps 入参。`movement_amplitude` 只出现在部分旧样例/响应中，未被当前对应参数表声明，不发送。
- 本预设不自动执行人物主体库、错峰生成、自定义水印或回调；这些不是把所有模型都塞进 `images` 即可正确表达的能力。

异步：提交取 `task_id`；`GET /ent/v2/tasks/{id}/creations`，状态字段 `state`：`created / queueing / processing / success / failed`，成功取 `creations[*].url`，错误 `err_code`，链接24小时有效。预设10秒查询、本地等待30分钟。

### 未转为执行预设的 Vidu 协议

- **Q3 Turbo 主体参考**要求 `subjects:[{name,images?,videos?,server_id?,voice_id?},…]`，不能与 `viduq3` 的平铺 `images` 协议互换。当前参考槽位不承载人物库实体或主体分组，不静默丢弃分组，也不把 Turbo 发送到普通Q3模板。
- **Q4 Preview** 精确 ID `viduq4-preview` 已有官方图生/参考页，图≤15、音频≤3（每段3–12秒）、时长3–16、分辨率 `540p/720p/1080p/2K/4K`；但 [V6] 参考页创建鉴权写 Token，查询鉴权写 Bearer，[V7] 图生查询又写 Token。概览还写1–16秒，详细页写3–16秒。**无法一致核实完整协议，所以不注册“看起来能用”的Q4预设。**

## 7. 模板、校验与离线测试边界

- `ModeSpec` 与有效参数来自共享 `modelModes` 契约；所有参数标签、用途说明、基本/高级分组均在预设声明，不由UI猜测。
- 图/视频/音频角色由 `JobRef.slot` 显式给定。`seedanceContent` 生成带角色的嵌套类型对象，供 Seedance 与H3共用；`wanMedia` 生成 `{type:slot,url}`。首尾槽位与参考槽位不混用。
- 通过“图片起步 / 视频起步 / 音频起步”拆分参考入口，保证必需素材至少一种存在；2.0没有纯音频入口。数量仍按官方上限，不以减小上限掩盖总量约束。
- **尚不能仅靠槽位检查自动保证的条件**：H3混合总数≤12、视频/音频时长总和、Wan输入视频+输出总时长、文件字节数/编码、人脸授权、画幅尺寸与首尾面积比。这些已写入预设notes和参数描述，用户仍须满足上游限制；不声称本轮提供了文件级媒体分析器。
- 请求只有模板声明字段；传入未声明旧参数不会被合并到请求。预览与真实发送共用同一路径，没有自动重试生成、隐式上传或额外付费探测。
- `presets.test.ts` 对 `builtInPresets` 全部执行 `validateProfile` 与严格schema校验；对每个新增模型的每个模式固定比较 `renderPreview` 的URL、鉴权、请求体，并以离线引用解析器比较真实发送路径与预览；另外覆盖Hailuo成功轮询后的file_id下载、无效组合、首尾缺图、2.0纯音频和Wan首帧混音频拒绝、未知字段不发送。
- 测试只证明配置与渲染契约，不证明账号权限、余额、远端开放状态或生成画面质量；不以单测替代真实付费验收。
