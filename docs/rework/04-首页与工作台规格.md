# 04 · 应用外壳、首页、工作台、资产

> 依据：即梦 10-17 实地采集（`AIGC/开发文档/实地采集-20261017/jimeng.md`）、线上开发平台 video-maker 的 Home / Create / Composer / Feed / Viewer 实现。

## 1. 即梦的痛点 → 我们的做法

| 即梦实测痛点 | 我们的做法 |
|---|---|
| `+` 上传槽直接弹系统文件框，无类型/数量/大小提示 | `+` 弹小菜单：本地上传 / 从资产库 / 从画布节点，菜单底部写明「图片 ≤ N 张 · 视频 ≤ N 个 · 单个 ≤ 30MB」（按当前模型声明）；同时支持拖入与粘贴 |
| `@` 无主体时点了没反应 | 空态面板：「还没有人物 · 从图片创建人物」 |
| `/` 弹窗无搜索，「技能」菜单有搜索，两处能力不一致 | 一个技能面板：`/` 和「技能」按钮打开同一面板，带搜索、最近使用 |
| 11 个模型平铺、无搜索/分组；不兼容只在 hover 才说明 | 模型选择器：搜索 + 按渠道分组 + 最近/收藏；与当前模式/参考素材不兼容的模型**直接显示灰态 + 原因行**，无需 hover |
| 参数条纯文字，「智能比例 / 2K / 2」挤在一个按钮里，热区分不清 | 参数条分段按钮：比例用画幅形状图标、分辨率、数量、时长各自独立可点，点哪段打开聚合面板并定位到对应分组 |
| 输入框不随内容增高 | 自动增高至视口 40%，之后内部滚动；长文可展开为全屏编辑 |
| 9k px 长会话只有「回到底部」 | 右侧细「生成目录」：每批结果一个缩略图刻度，悬停预览、点击跳转 |
| 同一结果的操作散落 4 处 | 结果卡统一操作区：悬停显示 5 个高频（下载 · 用作参考 · 再次生成 · 发送到画布 · 更多）；「更多」与查看器展示全部动作并带文字 |
| 资产页无上传，资产 = 生成历史 | 资产库独立：上传、生成、画布保存三种来源；悬停即可下载/收藏/更多 |
| 画布四个入口，新建另开标签页 | 画布只有一个入口（项目），同窗口打开 |
| 无快捷键面板 | 全局 `?` 快捷键面板，按页面分组 |

即梦值得保留的：同一 Composer 切换多种生成模式只换参数条、比例/分辨率/数量聚合面板、时长「滑块 + 数字」、首尾帧槽位标签写在槽内、结果元信息行「模型 · 时长 · 比例 · 分辨率」、`/ 技能` chip 行、Esc 一致退一层、克制的深色令牌。

## 2. 应用外壳

- 左侧导航：展开 220 / 收起 64（收起态悬停显示名称）。项目：首页 · 工作台 · 项目（画布）· 资产 · 人物；底部：任务（运行中数量角标）· 设置。
- 进入画布或舞台时导航自动收起为 64，画布顶栏的项目菜单可回首页。
- 全局浮层统一挂在外壳：查看器、资产选择器、快捷键面板、命令面板（⌘K）、任务抽屉、Toast。
- 主题插槽：`[data-theme]` + 设计 token（CSS 变量）+ 背景层 z-index 0（默认空，后续定制皮肤用）。

### 2.1 设计 token（深色默认，参考即梦与 LibTV 实测取中）

| token | 值 |
|---|---|
| `--bg` 页面 | `#121212` |
| `--surface-1` 侧栏/卡片 | `#1a1a1a` |
| `--surface-2` 浮层/菜单 | `#262626` |
| `--border` | `rgba(255,255,255,.08)` |
| `--text-1/2/3` | `#fafafa` / `rgba(255,255,255,.62)` / `rgba(255,255,255,.36)` |
| `--hover` | `rgba(255,255,255,.08)` |
| `--accent` | `#3b8cff`（可主题化） |
| 圆角 | 6 小按钮 · 10 菜单项/输入 · 12 卡片/浮层 · 20 Composer |
| 阴影（浮层） | `0 8px 48px rgba(0,0,0,.28)` |

浮层统一：底 `--surface-2`、圆角 12、宽度按类型固定（菜单 240、模型选择 400、参数面板 440），锚点在触发按钮正上方，碰撞时翻转。

## 3. 首页

```
          你好，今天想做什么？
 ┌───────────────────────────────────────────────┐
 │ [+]  输入想法、剧本或上传参考…  / 技能  @ 人物   │
 │ [Agent▾] [模型▾] [参数…]                    ➤ │
 └───────────────────────────────────────────────┘
   / 写剧本   / 拆分镜   / 角色三视图   / 全能参考视频   更多技能 ›
 最近项目（卡片，含「新建画布」）            最近生成（横向缩略图）
 进行中任务（有则显示）
```

- 模式：Agent（默认）/ 图片 / 视频 / 音频。Agent → 首页 Agent 会话（06）；图片/视频/音频 → 新建工作台会话并跳转（video-maker `startFreshDraft` 模式）。
- 渠道缺配置时，输入框上方显示一行「还没有可用的图片渠道 · 去配置」。
- 无营销位。

## 4. 工作台

布局沿用 video-maker 创作台：左会话栏（268，可收起）+ 中央记录流 + 底部悬浮 Composer。

- **会话栏**：新对话；搜索；置顶；重命名；按项目分组（可选）。
- **记录流**：`column-reverse`，最新在底部贴着 Composer；向上滚动接近顶部预取更早记录；滚动时 Composer 收成胶囊（video-maker 阈值：靠底 120 / 收起 56 / 展开 320），输入中不收起。
- **生成卡**：提示词（@ 引用胶囊可悬停看大图）· 元信息行（模型 · 时长 · 比例 · 分辨率 · 耗时）· 结果网格 · 卡片操作（重新编辑 · 再次生成 · 删除）。生成中显示进度与 0.1s 计时器。
- **结果悬停**：下载 · 用作参考 · 再次生成 · 发送到画布 · 更多（更多 = 全部编辑动作：高清、扩图、局部重绘、多角度、生成视频…，带文字）。
- **生成目录**：记录流右侧 12px 细条，每批一个刻度，悬停显示缩略图，点击跳转。
- **发送到画布**：选择项目（默认最近）→ 作为素材节点落到该画布视口中心；也可把结果直接拖到左侧导航「项目」上投放。

### 4.1 Composer（与画布共用组件）

- 参考区：`+` 菜单（§1）；拖入/粘贴；参考素材按类型独立编号（图1、图2、视1、音1），悬停大图，拖动排序；首尾帧模式下变为两个带内部标签的槽「首帧 / 尾帧」。
- 提示词编辑器：TipTap；`@` 引用素材/人物/文本片段；`/` 技能；风格/运镜/特效以胶囊插入，提交时展开。
- 参数条：模式 · 模型 · 比例（形状图标）· 分辨率 · 数量 · 时长（视频）· 摄像机控制 · 预设；全部由 02 的 `ModelSpec.params` 生成。
- 发送：⌘↵；按钮旁显示「将生成 2 张」；渠道有价格时显示预估。
- 约束就地提示：参考数量超限、时长超范围、提示词超长 → 参数条上直接标红并说明，发送按钮禁用并写原因。

## 5. 查看器

- 全屏遮罩（不切路由）：左大图/视频，←/→ 切换，滚轮缩放、拖动平移；右信息栏：提示词（可复制）、元信息、全部动作（两列带文字按钮）、重新编辑 / 再次生成。
- Esc 关闭；上层浮层（菜单）优先消费 Esc（video-maker 已验证的 `defaultPrevented` 规则）。

## 6. 资产与人物

- **资产**：类型页签（全部 / 图片 / 视频 / 音频 / 文本）· 来源筛选（上传 / 生成 / 画布保存）· 比例 / 分辨率 / 模型筛选 · 搜索 · 按日期分组网格；悬停：下载 · 收藏 · 更多；多选批量（下载 / 删除 / 加标签 / 发送到画布）；拖到画布或 Composer 即引用。页面有「上传」。
- **人物**：名字 + 主图（可多张）+ 音色 + 标签；可从任意图片节点/资产「创建人物」；在 `@` 中优先出现。空态说明人物的用途并给出「从图片创建」。

## 7. 设置

渠道（02）· ComfyUI（07）· Agent 模型与模式 · 外部 Agent（07）· 外观（主题插槽）· 存储位置 · 快捷键 · 导入导出。设置是独立页面（左分类 + 右内容），不再是一个超长弹窗。

## 8. 实现

- 从 video-maker 移植：`features/composer/*`、`features/feed/*`、`features/viewer/*`、`features/assets/*`、`components/ui/*`、`styles.css` token 与动效；把 `api.*` 换成 Tauri 命令与本地 SQLite 查询。
- 路由：`react-router` 8，页面懒加载，空闲预加载常用页与浮层。
- 本地数据：会话、生成记录、资产沿用 Rust SQLite；新表通过迁移添加。

### 8.1 当前工作台应用层契约

- `src/features/workbench/store/workbenchStore.ts` 导出 `useWorkbenchStore`；先调用 `initialize()`，使用 `createConversation/renameConversation/deleteConversation/selectConversation/setDraft` 管理独立会话，`submit` 返回本地任务编号。任务通过 `input` 保留提示词、模型、参数和引用；`results` 为真实生成结果，`failure.kind/message` 为分类失败。
- 图片/视频使用画布同一 `tauriAiGateway`，文本使用 `submitCustomChatCompletion`，音频使用设置中的已启用音频模型和 `generateAudio`。提交不要求活动画布，不发布画布生成事件，也不创建节点。`importResult(taskId, projectId, resultIndex)` 才显式向指定项目添加素材节点；活动项目走原批量节点/历史路径，未打开项目沿用项目记录和 imagePool 编解码，不切换当前项目。
- `poll/resume/recoverResult` 仅查询既有任务或取回既有结果，绝不再次提交；`cancelWaiting` 只暂停本地等待，不声称取消上游计费任务。没有任务编号的中断提交恢复为 `unknown`，不能伪装成安全重试。
- 会话和资产索引使用带版本、结构校验和事务提交确认的 IndexedDB `storyboard-copilot:workspace`（`documents` / `media`）；首次读取自动迁移旧 localStorage 会话与资产索引，旧值保留不覆盖。浏览器 data/blob 素材在持久记录前转存二进制 Blob，索引只保存 `asset-media:<id>`，避免已满的项目 localStorage 挤占工作台。桌面图片/视频复用原媒体文件持久化命令，生成任务仍使用既有原生任务 SQLite；目前没有新增会话 SQLite 表。清理站点/WebView 数据会删除本地索引与浏览器素材。浏览器上游任务刷新后恢复能力仍以原网关为准；文本/音频无持久上游任务编号，中断不自动重发。
- 渲染素材应异步调用 `getAssetDisplaySource(source)`，把稳定引用解析成当前会话可用的 blob URL；渠道请求和旧画布导入边界使用 `getAssetPortableSource(source)` 临时取字节，不将 blob URL 写回持久索引。`initialize()` 等待索引迁移/加载；`submit()` 等待参考素材与本地任务事务提交完成才发送付费请求。IndexedDB 真实故障公开 `storageStatus.mode = memory` 并阻止新付费提交，损坏或未来版本原数据不覆盖；浏览器磁盘存储仍受站点配额与系统空间限制。
- `src/features/assets/application/assetCatalog.ts` 的 `listAssets/resolveAsset` 聚合所有项目生成、上传和画布素材及工作台保存结果；`saveAsset/renameAsset/favoriteAsset/deleteAssetReference` 只维护资产引用/覆盖层，删除操作不删除用户文件或画布节点。原模型、提示词、尺寸等 metadata 保留，调试上下文不写入资产索引。


## 9. 验收

- 首页 → 输入「一只橘猫在屋顶看夕阳」→ 图片模式 → 发送 → 跳转工作台并出现生成卡与计时器。
- 工作台 200 批记录滚动流畅，目录跳转准确，加载更早记录不跳动。
- 结果「发送到画布」后在目标项目视口中心出现素材节点。
- 参考超限、时长越界、模型不兼容三种情况均在发送前就地说明原因。
