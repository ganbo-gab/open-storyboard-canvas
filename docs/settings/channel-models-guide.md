# 渠道与模型

当前入口：**设置与渠道 → 渠道与模型**。图片、视频、文本、音频和 3D 模型共同管理，音频没有单独的设置侧栏。

## 先理解两个层级

**渠道**保存服务地址、鉴权和可复用的接口协议。**模型**属于一个渠道，声明自己支持哪些输出、模式、参数和参考素材。一个专用服务可以只接一个模型；一个中转站也可以同时提供文本、图片、视频和音频模型。

“我的渠道”适合管理连接；“模型广场”适合找模型。模型广场可按类别、渠道、配置状态和名称过滤，并切换卡片或列表。类别按实际保存的操作声明计算，不根据模型名称或参考素材种类推测。

## 接入一个新渠道

1. 点击“接入渠道”，选择模板、让已配置的文本模型读取文档，或粘贴外部 AI 返回的配置。
2. 使用模板时先选请求协议，再填写 URL 与 API Key。模板问号中的模型仅为示例，不会自动加入。
3. 点击获取模型，或手动填写准确的上游模型 ID。勾选想接入的项，核对系统建议的类别，并为每项选择真实支持的请求协议。单个模型与多类别模型均可接入；名称识别不是能力测试。
4. 下一步核对模式、参数、参考槽位与请求预览。文本模型可以声明上下文、输出上限、多模态、工具与流式能力，声明必须符合上游实际支持范围。
5. 保存渠道。保存不会自动运行模型。免费读取模型列表只访问声明的列表接口；试运行在独立窗口审阅后才提交。

模板卡片的问号以及连接页的“接入指南”可查看这三步的说明、真实请求与轮询路径、参数类型及原始接口值。阅读指南后关闭弹窗，已填写的连接信息仍保留。

## 选择舒服的画面参数

图片、视频模型的“公共工作台参数”与模式参数都可以修改。模板接入同样支持自定义，不必重新从空白配置开始。

- 模板使用 `1024x1024` 这样的尺寸选项时，在“画面规格怎么选”选择“像素尺寸”或“比例 + 分辨率”，然后点“预览工作台”。后者只拆分显示，选中后仍发送原来的一个尺寸值，只提供模板已声明的有效组合；`auto` 等特殊选项保留。
- 默认按像素尺寸计算精确比例；长边为 1024、2048、4096 时标为 1K、2K、4K，其他长边显示实际像素，例如 1536px。服务商对分辨率档位的定义各不相同，可在“调整比例与分辨率标签”中修改显示标签，不修改接口真实值。
- 模板本身使用独立比例与分辨率字段时，保留这两个字段及其原始选项，不把 `1K` 自动换算成像素大小。
- 展开参数可继续调整名称、允许值、默认值、顺序和控件。视频时长检查单位及数字/字符串类型；新增字段还需在高级 JSON 的请求模板中绑定，再核对请求预览。

以上是展示和配置能力，不代表某个模型支持模板里的所有选项。以实际服务商文档为准；支持哪些尺寸、数量、参考图及视频时长，由你的渠道声明决定。

## 给现有渠道增加模型

- **同协议模型**：选择“沿用当前渠道模型”，输入另一个上游模型 ID，复制该模型的接口与参数声明。
- **另一类别**：选择“增加其他类别 / 接口模板”，挑选相应协议。仅复制这个模型的请求与结果格式，渠道地址和凭据保持原值；请确认中转站确实支持它。
- **模型发现**：点击“读取模型（免费）”，再从读取结果选择。上游通常只返回名称，不包含可靠的能力声明，因此一次只选择使用同一套接口的模型，不同类别分批处理。

有些协议依赖专用全局请求头。若它与现有渠道不兼容，界面会阻止直接复制，建议作为独立渠道接入。绑定了独立端点的模式，也不能只换输出类别而继续保留原端点；需要替换完整协议并校验。

## 状态怎么读

| 状态 | 含义 |
| --- | --- |
| 配置就绪 | 地址、声明与所需凭据具备基本条件，不保证上游当前可用 |
| 待完善 | 缺凭据、仍为占位地址或缺模型等 |
| 未测试 / 已测试 / 测试失败 | 独立记录的连接检查结果；悬停可看方法和时间 |
| 单模型 / 多模型 / 跨类别 | 这个渠道保存了多少模型，是否跨输出类别 |

修改配置后，旧测试标记会清除。模型列表可以读取，不代表每个模型都能生成；真实试运行可能产生费用。

## 音频与特殊接入

旧豆包本地 TTS、VoxCPM 模块已移除。旧素材、结果和项目历史保留；旧模型 ID 不再执行，也不会自动换成另一个供应商。需要再次生成时，请明确选择已接入的音频渠道。

通用音频使用 `audio.generate`，支持 JSON 中返回 URL、base64 或 data URL 的结果，以及带任务编号的异步查询。自定义音频模板是可编辑示例，需要按文档确认字段；直接返回 `audio/mpeg` / `audio/wav` 二进制流的接口当前需要适配。不要把所有标准 TTS 端点当成可直接套用的 JSON 接口。

ComfyUI、即梦 CLI 与外部 Agent 仍使用专用设置，因为它们的工作流、上传、登录与权限协议不同。

## 查问题与取回结果

渠道配置中展开模型，可以编辑公共参数和每个模式的参数：显示名称、类型、选项真实值、默认值、说明、顺序、基本或高级分组，以及按钮、下拉、数值滑条或隐藏。隐藏仅收起控件，不删除请求默认值。可先预览工作台效果，再检查请求并保存。

选项每行使用 `显示名称=接口值`，例如 `标准="1024x1024"`、`5秒=5`；字符串数字写 `5秒="5"`。修改接口字段时，也需同步核对请求模板。

macOS 首次调用可能要求系统钥匙串授权。当前进程会复用已授权凭据，拒绝后暂停查询，不再后台循环弹窗。任务卡的“重新授权并查询原结果”仅恢复原任务；渠道 API Key 栏也有重新授权入口。

从生成记录的“详细信息”查看当时的模型、参数、任务 ID、错误和结果；可以复制脱敏诊断。旧记录未保存的信息会显示未记录。

“取回原结果”只使用原任务或保存的结果地址。“再次生成”才会创建新任务。对于原任务句柄丢失、地址过期或未保存的同步返回，应用无法凭空恢复，也不会自动重新收费生成。
