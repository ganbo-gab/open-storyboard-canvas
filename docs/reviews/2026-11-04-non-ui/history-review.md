## 现源码复核到的明确功能不一致（需主审决定优先级）

这些都已存在于最后 BacklogMap / frontend-pause-checkpoint 资料；本次再次核对真实源码，尚未改动或运行浏览器复现。它们说明剩余事项不只是视觉。

1. **视频裁剪单位不一致**：`src/features/canvas/ui/MediaEditDialog.tsx:71` 用视频像素宽高生成 `video.crop.rect`，UI 还以整数/像素输入（:188–191）；`src/features/canvas/application/media/types.ts:56–60` 却要求 x+width/y+height ≤ 1。普通 1920×1080 原尺寸或 100×100 裁剪会被 invalid-range 拒绝。应用层规范是归一化，应在调用边界统一转换。
2. **音频倍速范围不一致**：MediaEditDialog.tsx:185 允许 0.25–4；media/types.ts:68–69 只允许 0.5–2。0.25/4 等界面合法值实际失败。属于参数接线错误。
3. **缩短舞台时长静默压帧**：`src/features/canvas/ui/useDirectorStudioMotion.ts:413–423` 把所有越界镜头/对象/动作帧直接压到末尾，可能把多个不同时间帧合并/丢失时序；`src/features/stage/application/stageOperations.ts:269–272` 已有 timelineContentEnd 超时拒绝。UI 自行改文档绕过统一保护。
4. **画路线删除区间后所有关键帧**：useDirectorStudioMotion.ts:474–503 固定四秒，并只保留 `< startTime` 帧，因此绘制 4s 局部路线会删掉之后原本还有的动作/镜头路径。stageOperations.ts:214–249 的 `trajectory.set` 已有保留区间外帧、人物自动步行动作；UI 尚未复用。
5. **舞台 hidden/locked 等为应用层完成，用户工作流未完成**：旧眼睛是隐藏标签；独立多选、锁定、四视角/精确时刻控件仍缺。应单列“业务 API 已实现、入口未接”，不归为纯美化。

## 确认的非纯前端实现缺项：ComfyUI 实时进度

规格 `docs/rework/07-ComfyUI与外部Agent接入.md:36–39` 要求 WebSocket 当前节点/采样步数、断线退回 history。

- `src/features/channels/adapters/comfyui/adapter.ts:134–149` 只有可选 `dependencies.ws` 路径，测试里存在 socket。
- **生产入口 `src/features/channels/runtime/comfyExecution.ts:164–189` 返回的 dependencies 只有 getSecrets/http，从不传 ws。** 全生产 createComfyUIAdapter 调用都在该文件，故运行中永远只走轮询。
- 此外 submit（:327）和 poll（:270）分别创建 adapter，WS session 是 adapter closure 内状态；仅注入 ws 也不够，必须让生命周期共享或转移状态。
- adapter.ts:185–186 能返回 pending 的 progress/message，但 runtime :284 只保存 last_poll_at，丢弃进度和节点文本。需要真实通路 DTO/状态投影，而非加百分比 UI。
- 后果：不妨碍已实现的提交/history/结果取回，但文档要求的真实节点进度还没有完成。这与最后 BacklogMap I5“missing/非纯前端”一致。
