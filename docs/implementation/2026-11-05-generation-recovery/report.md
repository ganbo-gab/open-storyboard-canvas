# 生成查询与工作台修复验收

## 真实问题与根因

用户反馈启动修复后不再弹钥匙串，但图片提交、查询仍反复授权；拒绝后仍弹，中转已生成而工作台没有结果。

只读检查真实 ai_generation_jobs：最新 gpt-image-2 记录已有原 external_task_id，状态 running/poll，声明每2秒 POST /v1/draw/result；快照尚无 outputs/assets。未读取真实 Keychain、未请求真实中转站、未改用户任务。

原生每个 HTTP 请求单独解析凭据，导致提交、轮询和鉴权下载重复读钥匙串；TemplateAdapter.poll 又把凭据拒绝吞为临时网络 pending，持续重试。之前仅修启动存在检查，未覆盖这条实际生成链路。

## 本轮修复

- 原生成功读取的凭据只在进程内保存，不进入 JavaScript/日志/持久化。连续查询复用授权；闲置15分钟（包括睡眠、时钟回拨）后下次读取阻断，不自动弹授权。
- 拒绝或读取失败记为阻断；只有明确的 secret_retry_access 才重新访问系统。修改/删除凭据会使缓存失效，存在检查不能解除阻断。
- macOS 的取消、拒绝、禁止交互等真实错误码正确归类为 locked。
- 凭据错误覆盖提交前素材准备、提交、轮询、结果下载、文本流式和3D下载。轮询立即暂停为可恢复状态，保留原任务编号或已知结果地址。
- 恢复成功清除旧凭据错误；状态保存失败也在内存暂停，避免自动恢复循环。极晚的存在检查不能覆盖重新授权后的状态。
- 工作台任务卡提供“重新授权并查询原结果”；提交前失败只授权，不自动再生成。渠道 API Key 栏提供重新授权入口，Agent 等路径也能由此恢复。
- 参数 DIY 支持公共参数与模式参数：显示名称、真实接口字段、类型、选项和默认值、说明、排序、必填、基本/高级分组，按钮/下拉/滑条/隐藏及预览。隐藏仅隐藏控件，请求默认值保留。
- 旧渠道 size/aspectRatio 等获得友好名称；未明确分组的 webHook/shutProgress 放在高级项。不会悄悄改变旧请求的字段或数值类型。
- 引用在光标处触发，保留输入焦点过滤；方向键、Enter/Tab选择，替换完整触发范围，避免 @@图1。已知旧重复标记同步规范化到草稿；引用与候选含素材缩略图。工具栏 @ 直接打开引用，素材管理独立。
- 修复弹层入场动画参与测量导致右边缘偏移，按实际布局尺寸限位；参数弹层不再整块跳到左侧历史栏。

- 前端全量：274个文件、2523项通过。Rust全量：213项通过。随后少量界面入口/菜单测量调整的目标回归通过，生产TypeScript/构建与原生打包通过。
- 原生凭据24项含并发16次仅读取一次、拒绝后不自动重读、显式授权、闲置过期、写删失败失效。
- 真实 loopback HTTP 使用假凭据库：提交、两次轮询、鉴权SVG下载只读取一次凭据；连续四次被拒查询仅读一次、发出零网络请求；显式授权后只查询已受理任务。不是供应商或真实 Keychain 测试。

## 边界

没有读取/更改真实钥匙串或其ACL，不能把假凭据库和查询结构测试等同于用户机器上的授权实测。首次访问旧条目仍可能由macOS要求授权；修复针对重复访问与拒绝后自动循环。

原生缓存未接系统锁屏即时撤权；外部钥匙串改动在当前进程中不是即时生效，应用内修改/删除或显式重新授权会失效。缓存不落盘，关闭软件清除。

用户真实任务只确认编号仍在，尚未从真实上游取回图片。新包应使用原任务的重新授权/查询入口，不点击再次生成。远端过期等供应商边界仍适用。

Windows未实机测试。没有把本轮定向流程验收称为整个软件不存在潜在问题。Git索引保持原SHA256，未动用户1420服务、CLI配置或真实项目。
