# 修复版验收说明

版本：0.2.0-next.1，2026-11-05 修复版，Apple Silicon / arm64，macOS 11 及以上。

## 本轮修复

- Agent：图片粘贴/拖放/上传、对话附件预览；原生读取busy与跨会话迟到附件保护；真实asset ID授权引用；Anthropic流式工具参数拼接；标题/新建/关闭布局。
- 画布：轻菜单互斥与外部/Escape关闭，编辑面板实色且位于工具栏上方，复杂编辑窗居中；菜单不随节点缩放，边缘翻转/限位。
- 工具栏：节点默认5项、侧栏生成分组，其余进入更多；可调整显示数量、顺序和项目，重载保留。
- 参数：对象尺寸标签与结构等价校验；长数值枚举按声明值滑动，精确选择保留真实wire类型。
- 渠道：协议→URL/Key→读取或手填模型→勾选与类型/协议校正→高级审阅；旧模型样例仅帮助。文本上下文、多模态、工具、流式能力可配置，各模型独立协议投影。
- 自定义图床：移除内置PiXhost/私域默认服务和换token流程，旧配置禁用。保留自定义POST URL/字段/请求头/响应路径，上传仍走明确确认。
- ComfyUI：AI只分析工作流结构、建议绑定，用户审阅应用；不自动运行工作流。
- 尺寸：Agent、适合的编辑窗口可调整并记忆；外观设置可锁定。
- 性能：手势过程中实时移动，仅结束提交视口到canonical/project；冷缩略图解码避让自定义连续手势。
- Mac：原生红黄绿按钮、全屏/退出/放大/还原，双击标题栏与Ctrl+Cmd+F；取消整窗透明vibrancy和整画布入场变换。首页卡片宽度修复。Windows按钮与F11/状态同步修复。

## 明确边界

- Windows未实机验收，测试覆盖模拟native事件，不证明Windows Snap、多显示器或DPI行为。
- 真实供应商/真实剪贴板多种来源、付费Agent搭建/ComfyUI执行未跑；未触真实Keychain或付费接口。原生剪贴板路径/优先级/竞态有针对性回归。
- 不宣称“千节点60fps”或“已无所有卡顿”。Ego原性能采样有1000ms节流不可用；确定消除了逐帧canonical/project广播，20moves为0commit、release为1，冷图任务让出手势。原生操作仅为行为检查，不是presentation帧率测量。
- Stage的V1空间轨道编排技术债仍有，复杂编辑器拆分继续渐进处理；本轮未重写底层或承诺无未知bug。
- 旧任务取回仍需有效原任务ID/结果地址/本地素材，过期或从未保存的结果无法凭空恢复，不会自动重新收费生成。
- 全仓git diff --check仅有此前舞台规格文件EOF空行；本轮产品/文档目标diff检查通过。cargo fmt --check存在历史大范围差异，未全仓格式化。

## 给用户的测试顺序

1. 打开修复版，测试Mac绿灯全屏、退出、Option绿灯放大/还原与双击标题栏。
2. 打开原“火”项目，缩小后平移；检查节点菜单在四边缘、Agent展开时的位置。
3. Agent粘贴截图、上传图片、发送后看缩略图，切换会话后再回来；用真实支持工具的模型测试场景构建。
4. 模板接入自己的服务，获取/手填模型，调整类别与协议，查看高级能力后保存。
5. 工具栏“更多→自定义”、面板拖动和外观锁定；工作台时长滑条与精确值。
