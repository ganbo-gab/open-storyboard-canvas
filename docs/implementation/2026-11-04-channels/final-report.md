# 旧音频移除、统一渠道广场与舞台结构优化

用户确认移除整套豆包本地 TTS / VoxCPM 功能，并要求音频归入统一渠道、渠道管理参考 video-maker 模型广场、优化舞台技术债、更新 README 后交其验收。

## 本轮交付

- 删除旧音频设置页、默认供应商、网关与其独立输入协议。设置迁移和旧备份导入显式剔除废弃配置，防止恢复后重新启用；旧音频素材和历史字段保留，旧模型 ID 拒绝执行且不会静默换模型。画布、工作台和 Agent 音频目录统一使用渠道。
- 设置入口合并为“渠道与模型”，移除重复“我的配置”入口和独立音频入口；旧 settings category 指向统一页面。
- “我的渠道”与“模型广场”两种视图，支持能力、渠道、状态、搜索、卡片/列表。明确单模型、同类多模型、跨类别渠道。配置状态与测试结果分开，缺凭据或占位地址不当作可用。
- 模板接入可勾选需要的模型；频道模型管理支持分类筛选、显示名/上游 ID、模式/参数、复制模型、免费发现后的显式添加。跨类别模板仅绑定到新模型，不覆盖原模型协议；不兼容的专用全局请求头阻止直接复制并提示独立接入。
- 发现模型的迟到请求不会串到另一个渠道；保存与发现使用独立等待状态及同步保存保护。绑定了端点的模式禁止只改类别保留旧端点。相应行为回归已补。
- 自定义 JSON 音频模板提供可编辑入口。明确它是示例，不宣称支持任意标准 TTS 二进制响应。语音工作台输入提示与参数名调整为对应内容。
- 舞台截图相关职责提取到应用模块和两个生命周期 hook，DirectorStudioShell 从 3709 行减到 3411 行（298 行）。沿用数据和命令，修复同 tick 重复发送及卸载后迟到写入。布局与主要操作保持。
- README 按当前产品重写：工作台、渠道/模型、画布、舞台、三作用域 Agent、追溯与恢复、首次使用、限制与目录。替换为六张当前桌面截图，保留赞助与授权归属；新增 channel-models-guide.md，旧规格增补当前音频契约。

## 仍需如实保留的边界

舞台仍有较大的渲染和编排文件；本轮是有界职责提取，不代表全部技术债消除。V1 空间轨道不是独立空间 clip 系统，步频联动没有新增承诺。Agent 的模型质量、权限与真实供应商/CLI/原生编解码仍需在真实环境验证。画布 undo 不撤销已提交付费请求、知识库文件写入或下载，README 已明确三作用域能力与撤销边界。

音频通用渠道支持 JSON URL/base64/data URL 和异步查询；直接 audio/mpeg/audio/wav 二进制返回需要适配。旧音频适配器已按用户要求删除，没有伪装成新模板。
