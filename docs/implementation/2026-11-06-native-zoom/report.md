# Mac 原生千节点缩放优化验收（2026-11-07）

## 结果

已定位并大幅降低 macOS WKWebView 中千条独立 SVG 连线缩放时的绘制停顿。最终产品原生样本中，10%→约100%→10% 连续缩放的 rAF P95 为42/44/51ms、最大78/80/95ms；修前同机原生多次P95约505–758ms、最大793–968ms。该范围显著改善，但仍有长帧，**不承诺恒定60fps或任意千节点项目零卡顿**。

10%平移P95为37ms，首次开始仍有414ms长帧；停止阶段最大133ms。60%/100%平移P95均18ms、最大29/24ms。节点拖动、断线、撤销、窗口缩放与GPU丢失回退已验证，详见下文。

## 原因与方案选择

真正Tauri release / WKWebView分阶段标点与前台对照确认：wheel处理同步max约1–15ms，视口应用约10–15ms，大停顿主要发生在连线绘制。仅关闭节点绘制无改善；保留1000节点/350图片而临时关闭连线，P95降至33ms。此操作只用于诊断，没有作为产品优化交付。

逐路径对照发现移除默认透明点击路径无稳定改善，移除自定义透明点击路径后仍约350ms，说明可见边本身也昂贵。Canvas2D每条重画仍P95184–231ms；合并半透明路径会改变交叉叠加；位图缓存虽快，但放大模糊且编码可阻塞。因此采用 **单个WebGL2画布绘制缓存的矢量连线**，保留ReactFlow、SVG命中区域、业务数据、路由和历史，不重写整个画布系统。

## 最终产品行为

- 当前画布完整挂载且至少160条普通连线时，空闲分批采集现有SVG的实际路径与样式，准备GPU几何；单份缓存支持至多1000条边，更多或不支持的几何安全回退SVG。单顶点缓冲限制约32MB，屏幕缓冲另有尺寸上限。
- 准备成功并且首帧绘制成功后，GPU接管普通连线的可见墨迹；静止保持缓存画面，避免每次松开都重绘千条SVG。停止后不再连续绘制，只在视口/尺寸/交互状态变化时刷新。
- SVG保留在DOM内，静止时宽命中路径使用`stroke:none`与`pointer-events:stroke`；hover、键盘焦点、连接和节点操作恢复SVG。真实原生点击与撤销已确认，不依赖合成click假装命中。
- 默认实线butt/miter、纯色/半透明和绝对M/L/C/Q路径支持GPU；曲线近似误差不超过0.5个世界坐标像素，运动中高倍率可能有轻微折线差异。绘制保留边顺序和逐边alpha，不按样式合并重叠线。
- 普通层级中出现箭头、虚线、滤镜、渐变、额外变换等不支持效果，整份缓存回退以保留透明叠层；不同层级SVG保留自己的渲染。选中/处理中样式通过SVG属性观察失效。
- 图几何、Flow展示边、路由、主题或样式变化立即废弃缓存；文字/进度等不改几何的节点数据沿用共享几何索引。分批准备期间DOM替换会取消旧结果，避免GPU和新SVG重复绘制。
- GPU不可用、编译/上传/绘制失败、context loss、隐藏窗口或卸载都恢复SVG；canvas不接收鼠标，不写项目数据。窗口尺寸与DPR变化更新屏幕缓冲。

## 验收环境与边界

Apple M3 / 16GB / macOS15.7.4，真正Tauri release隔离QA，identifier=`com.ganbo-gab.storyboard-mac-perf1106`，窗口内容1440×937、画布1440×901、DPR2。保留产品原生分支和SQLite。没有复制用户“火”项目、渠道或凭据，也没有发供应商生成请求。

夹具1000节点（350图片上传节点、630图片生成节点、20导演台入口），1000条正确注册的`disconnectableEdge`，350张已解码512×320独立PNG。未打开3D舞台。它是合成渲染压力图，部分连接不构成可执行业务DAG；不是所有真实项目的代表。

测量为原生进程内固定脚本输入，明确`trusted:false`；rAF间隔不是呈现FPS或硬件输入延迟。最终矩阵监听`visibilitychange`与`blur`，全程无后台/失焦。用户已明确授权AppleScript/open只操作隔离QA窗口以保持前台。旧Chromium夹具使用过错误边类型，其数字不用于本次结果。

## 交互正确性

- 在10%下，通过原生`elementFromPoint`找到离中心线0.6个CSS像素的透明宽命中区；真实CUA点击选中`qa-e-42`，双击只删该边（1000→999）、新增一条历史，真实⌘Z恢复1000。
- 原生脚本拖动1/5/10节点：精确只移动对应节点，每次一条历史，撤销精确还原；P95为51/29/27ms，单节点首次最大119ms仍保留。该组只在结束记录前台，不扩展为硬件连续拖动帧率证明。
- 原生窗口放大到画布1710×957，GPU缓冲3420×1914；还原1440×901，缓冲2880×1802。
- 原生主动触发GPU context loss后，GPU层退出、canvas隐藏，1000条基础SVG全部恢复，canonical仍1000边。
- 生命周期、箭头/特殊样式回退、透明叠层、异步DOM替换、相对单位拒绝、focus恢复、失效/取消/卸载和数据内容变化回归见测试。

证据：[原生功能记录](evidence/native-functional-verification.json)、[拖动与撤销](evidence/final-drag-results.json)、[宽命中撤销记录](evidence/native-hit-undo.json)。GPU初版原生截图检查连线路径/节点遮挡正确；没有声称跨所有主题/模型/Windows设备进行像素级验收。
