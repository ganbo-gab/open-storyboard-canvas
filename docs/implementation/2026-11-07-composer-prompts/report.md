# 2026-11-07 摄像机弹窗、提示词预设与图片功能

## 对照需求

只读检查了 AIGC 文件夹的《AIGC工具的画布相关要求.docx》和《AIGC项目说明.docx》。画布文档第 244–246 段要求 `/` 包含图片功能区同类功能，第 258 段要求预设与 `/` 入口相通，第 260–272 段描述摄像机常用预设、场景说明和启用状态。第 33/39/43 段强调先选择图片功能、保留原图引用、继续补充提示后提交。最新用户要求的独立弹窗与可编辑提示词正文优先于旧文档仅使用选中标签的描述。

本轮补齐上述直接关联入口；没有把原文中的其他指令当作当前操作授权。人脸框选定位、专门的情绪调节等仍缺少独立工具，已列为后续功能缺口，不能将通用提示词模板等同于完成这些工具。

## 完成内容

- 摄像机使用共享 UiModal，Portal 到 body，脱离节点变换；尺寸可调整，支持取消、保存、逐层 Esc 和焦点恢复。参数在生成时追加摄影提示词，不是直接控制模型的物理相机。
- “保存为预设”直接打开命名窗口，“我的预设”打开列表。修复旧设备编号、删除全部预设后默认项复活、存储失败却显示成功。Zod 校验并映射已知旧编号；未知条目/额外字段保留，损坏根数据不覆盖。
- 所有使用 NodeComposer 的图片、视频、AI 文本、音频、分镜节点都有显式“预设”和“/ 功能”。自定义预设与提示词库收藏可搜索，选择后追加或替换输入框正文，再由用户修改并生成。分镜写入当前镜头的草稿。
- 图片节点增加“图片功能”，复用已有七项可配置模板（多机位、剧情推演、连续分镜、光影、三视图、前后帧推测）。有多张参考图时先选目标；写入相应 `@图` 和模板，其他引用保持上下文。可打开选定参考图的既有内容编辑器。
- 新选项直接写入草稿，并清除旧隐藏预设/功能 ID，避免正文与隐藏前缀重复。追加保留未提交的本地输入，空输入直接填写，替换是明确选项。旧保存节点仍能读取旧标记，并提供“写入输入框”入口。
- `/` 由实际文档变化识别，支持半角/全角斜杠、中文输入、光标处搜索、上下键、Enter/Tab 应用和 Esc。URL 中的斜杠不触发；应用后只移除命令片段。显式按钮使用同一命令列表；图片/视频列表也能打开摄像机。
- 修复独立弹窗内事件沿 React Portal 冒泡到节点的问题：按钮的方向键、Space、点击不会再移动或重选底层节点。
