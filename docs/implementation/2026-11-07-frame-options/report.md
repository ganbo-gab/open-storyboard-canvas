# 渠道尺寸、比例与分辨率编辑

日期：2026-11-07。用户指出选择比例+分辨率后原尺寸编辑仍是文本，要求勾选操作；随后明确需要分辨率与比例独立选择、自由组合。本轮按最终要求实现。

## 最终行为

- 像素显示：当前尺寸可逐项勾选，常见尺寸在可展开候选区，默认值用下拉选择；取消当前默认值改为其余第一项，最后一项不能直接取消。原始参数、标签和文本编辑放入高级区域。
- 比例+分辨率显示：两组独立复选框。分辨率在前、比例在后；例如1K/2K×1:1/16:9，应用后得到4个实际尺寸映射。常见13比例直接可选，支持自定义比例和档位。
- 像素接口保留一个原始size字段；已有映射使用原值。新组合按所选档位长边计算建议像素（1K=1024、2K=2048、4K=4096，短边四舍五入），界面说明供应商像素步长和尺寸限制仍需核对。实际映射可编辑，应用只是修改配置，不调用生成；未知HD/P等档不猜测，需手填接口尺寸。
- 映射缺失或不同组合使用同一接口值时阻止应用。auto等特殊值独立保留，默认值仍有效；不会静默启用全部候选，也不声称所有模型支持所有尺寸。
- 默认值与工作台使用分辨率、比例两个独立选择器。完整矩阵中切换任意一轴保留另一轴。旧稀疏映射没有对应组合时，只落到已声明的有效值，不发送未声明尺寸。
- 原生已有ratio/resolution两字段的图片/视频模板分别用复选框编辑，保留原字段及K/P大小写。像素候选沿用x/*/×分隔符；自定义标签与size元数据保留。复杂复合JSON参数、没有对应声明的宽高参数继续使用原高级编辑，未自动拆分或猜测能力。
- 取消像素项时卡片原位置不跳动，重新添加暂时取消的自定义项保留原元数据。切换模型/模式重建局部编辑状态，避免临时候选混到另一个模型。
