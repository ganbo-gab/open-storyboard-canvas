# 画布鼠标自定义恢复与扩展

2026-11-08。实现完成后先交付 Mac Apple Silicon 验收版 0.2.1-preview.1，随后纳入正式版本 v0.2.1；原生 macOS/WKWebView 和 Windows/WebView2 的 GUI 本轮未重测。

## 用户行为

- 左、中、右键分别配置单击、双击、拖动，共九项；滚轮继续支持自动、缩放和平移。
- 单击/双击可选选择或清空、菜单、快速创建、适合屏幕、不执行；拖动可选平移、框选、不执行。
- 推荐预设：左拖空白平移、左双击空白快建、右单击菜单、右拖框选、中拖平移。传统预设：左拖框选、中拖平移；用户可继续逐项修改，保存后生效。
- 左键节点选择、移动、双击编辑不受空白手势映射影响。抓手只覆盖空白左拖，节点继续可编辑；Space 临时平移，Shift 追加框选/临时左拖框选。
- 右键拖动不会在释放后弹出菜单，菜单和快建互斥；配置了双击动作时会区分单击/双击，转去控件或其他界面时取消待定单击。
- 快捷帮助按当前映射展示；空画布使用稳定的 Tab 提示，不再把可修改的双击写死。

## 兼容与边界

v0.2.0 迁移曾直接删除 v0.1.27 的六槽鼠标配置。本轮设置版本升为 26，统一九槽 Zod 合同。仍在旧版中的配置与旧备份可转换；已被前次迁移覆盖的数据不能凭空找回。

保留 v0.2.0 用户已有左拖/滚轮习惯，以及该版的右拖平移；用户选择推荐预设即可切换右拖框选。新九槽为运行时唯一权威，旧 canvasLeftDragMode 只作兼容镜像。无鼠标字段的设置备份不会重置当前习惯，非法动作在导入前整体拒绝。

自管手势只接管画布区域，输入框、按钮、连线端口、浮层和内嵌编辑器保留原控制。鼠标移动时仅更新局部选框或经 rAF 更新视口；选区释放时才做一次节点相交和选择提交，平移仅在结束时持久化。
