# 2026-11-07 统一剪贴板与引用移除

## 当前修复

- 引用缩略图新增独立 X。图片本身仍可插入 @；X 只移除当前节点引用与其入边，不删源节点或其他下游连线。同步清理模型槽位与失效 token，一次映射保留剩余引用身份（旧图2变图1，不误删旧图10）。
- 标签组、多帧等一条连线提供多个引用时，明确确认连带范围再断开消费者侧连线，不修改共享组。分镜同时更新各镜头引用，当前镜头用未提交草稿；一次图编辑一次撤销。
- 复制节点写入系统纯文本剪贴板，采用版本标记和 JSON 节点/内部连线包。外部应用可粘贴文本，画布还原节点；不再依赖仅在当前组件内存中的副本或图片指纹判断。
- 快捷键与右键共用粘贴处理。桌面二者同读 Rust/arboard 系统剪贴板；浏览器快捷键使用真实 paste 事件的文本/文件，右键使用浏览器 Clipboard API，不再在失败后悄悄降级成其他内容。
- 支持原生文件列表（Finder/Explorer）及图片像素；文件列表优先于文件图标/缩略图。独立媒体路径/URL 走既有素材导入器；夹着媒体 URL 的普通段落保留完整文字。
- 原生快捷键读取鼠标相对当前窗口客户区的位置（物理像素按当前窗口 scale factor 换算），结合粘贴开始时视口换算；右键保留右键落点。DOM pointer 捕获覆盖重新进入、节点阻止冒泡和窗口位置变化。
- 读取剪贴板前固定落点/项目；切换项目不把迟到数据写到新项目。空白处粘贴不覆盖仍被选中的素材。粘贴新生成节点不触发输入区展开时自动平移，保持鼠标与落点关系。
- 结构校验在写图前进行；未知节点、无效分组循环、损坏关键字段明确报错。复制后的生成状态仍由既有复制服务清理，不自动重提请求。
