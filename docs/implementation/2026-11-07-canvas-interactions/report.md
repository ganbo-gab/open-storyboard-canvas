# 2026-11-07 画布连线与浮层修复

## 用户反馈与结果

| 问题 | 修复与验证 |
| --- | --- |
| 右侧拖线起点偏移 | 节点挂载、类型或实际宽高变化后刷新 React Flow 端口缓存；浏览器实际拖线验证起点正常 |
| AI 图片左侧不能开始连线 | 可手动接入的输入端允许开始拖线，输出端允许接收反向拖线；依然按来源→目标保存，保留类型与重复连接限制 |
| 已连接的线落在端口上方 | 修复实际节点高度 300、端口缓存仍按 220 计算的 40px 纵向偏差；多档缩放验收通过 |
| 再次点击已打开按钮仍弹出 | 外部按下关闭逻辑排除自身触发器，交给 click 切换一次，避免 pointerdown 关闭后 click 又打开 |
| 移动节点后弹层留在原处 | 菜单保留真实触发器并跟踪其屏幕位置；拖动所属节点保留弹层，点击别处、Esc、失焦或打开同级浮层按层级关闭 |

共享修复覆盖 MenuSurface、UiSelect、节点工具面板和 Tooltip，并更新画布模型/模式/参数、节点/选择工具栏、侧栏创建菜单、缩放、批量堆叠、提示词 @/斜杠、工作台项目与记录菜单的锚点。旧工具面板从按钮实时位置计算；备用锚点跟随所属节点位移。相同工具再次点击可收起。

额外修复下拉框靠近窗口底部时用估算高度造成的触发器遮挡；Esc 先关闭最上层子菜单。提示气泡从等待显示阶段就可被菜单、对话框、按下、滚轮、滚动和窗口变化取消，避免延迟冒到新浮层上方。

## 性能边界

- 端口测量仅由挂载、类型及尺寸变化触发，平移和缩放不触发全图重测。
- 仅已打开浮层跟踪自己的触发器；位置不变不提交新的位置状态，关闭后移除 rAF、ResizeObserver 与监听器。
- 闲置 Tooltip 没有全局事件监听；等待、显示、取消与卸载成对清理。
- 本轮验证交互正确性，不重新宣称任意千节点场景恒定帧率。

## 验证

完整 Vitest：**334 文件 / 3019 项通过**；TypeScript、生产构建、`git diff --check` 通过。新增真实 React Flow 端口缓存/反向连接回归、共享浮层事件时序与跟随/清理回归、工具面板切换、Tooltip 计时器竞态测试。

隔离 Chromium（1538，Ego 工作区 24，已结束）实际鼠标验证：重复点击模型按钮关闭；从图片左输入拖到素材右输出创建正确方向的连接；57% 缩放时拖动节点，模式菜单保持打开并同幅移动；右侧拖线预览对齐。10%、25%、57%、71%、100%、150% 的端点偏差不超过约 1.5 CSS px（可见端口中心与路径边界差异）。证据：`geometry-matrix.json`、`reverse-connection.png`、`menu-follow.png`。

独立 Tauri/WKWebView 验收应用使用隔离标识 `com.ganbo-gab.storyboard-interactions1107`，没有读取真实项目、渠道或密钥，没有生成调用：

- 原生实际点击模型按钮，打开后再点同一按钮，菜单消失。
- 原生实际鼠标从 AI 图片左端拖到上传素材右端，正确创建上传素材→AI 图片连接；引用素材出现在输入区，自动模式显示“图片编辑”。
- 原生 10% 至 150% 的几何矩阵最大偏差为来源 3px、目标 1.5px（端口边界/中心偏差，随缩放线性变化），原来的 40px 纵向偏差消失。见 `native-geometry-matrix.json`。
- 原生程序性节点移动后，菜单与节点最终均移动 (-70,-50)px。连续原生鼠标拖动复测受到自动化 `noWindowsAvailable`/桌面空间限制；该段不能算完整原生鼠标跟随验收。浏览器中的真实拖动跟随已经通过。
- 保留失败测量：WebKit `getScreenCTM()` 未纳入外层 CSS 视口变换，直接比较产生虚假百像素误差（`native-geometry-ctm-rejected.json`）；采用实际视口变换与 DOM 端口位置复核。后台原生窗口 `visibility=hidden`、1200ms 内 rAF=0（`native-follow-visibility.json`），不把后台延迟当作前台性能结果。

原生包包含五项主要修复；最后追加的 Tooltip 生命周期修复通过专项 26 项（含已有 Menu）和完整回归，进入正式包，未重新进行原生气泡视觉验收。Windows 原生本轮未测。
