# 舞台错误、存储与窗口适配

日期：2026-11-07。用户先反馈普通窗口下尺寸选项文字重叠，随后补充舞台 Agent 长错误、误报账户额度、左键旋转视角及建模/快捷键能力问题。本轮一名 helper 负责协议与分类，其余由主代理集成；不操作 Git 索引、用户项目、渠道凭据或真实供应商调用。

## 渠道窗口适配

根因：带标题和说明的两张卡片复用了 `.ui-tile` 的横排、固定 30px 高及 `nowrap`，且固定两列。新增局部样式，标题与说明分行，卡片自动高度；按组件实际可用宽度自动在一列/两列间切换。父级栅格与表单允许收缩，参数映射窄时把接口值单独放一行，标题与预览按钮可换行。

生产 Chromium 检查 960、1100、1280、1440、1710、1920 CSS px，文字 Range 均在卡片内且卡片不重叠。检查中英文、切换选择及展开标签映射。Mac Tauri 独立验收包实际进入同一模板→连接→手填模型→参数页，1280 CSS px 下看见上下卡片及正常换行；后续窗口消失，没有把全宽矩阵算作原生验收。未保存临时渠道，也未发出测试请求。

## 舞台 Agent

- 模型严格 schema 用 `null` 表示省略的可选值。`stage_command` 外层可接受单命令或数组，但解码先处理数组、没选中数组联合类型，导致成员缺少领域 schema，批次内可选 null 未移除。现先选择正确联合分支再递归解码；非法字段、无效命令、空批次及超过 100 项仍拒绝。真实 SDK/控制器验证单条与批次均正确执行，批次保持一步撤销。
- 原领域 schema 明确允许 null 的字段保留其清空语义：机位跟踪目标、动作/姿势选择可以实际清空。仅原字段不允许 null 时，才把严格模式生成的可选 null 还原为未填写。工具说明提示模型：严格 schema 要求提交可清空字段时，不想修改的值须从当前场景读取并保留。
- 校验失败生成具体字段路径和类型的简短诊断，不再把所有无关 union 分支堆成数千行。长错误 UI 默认至多 180 字和三行；已有后续步骤或回合结束时，旧工具错误收成一行。点击可展开、滚动和复制已保留的脱敏错误，展开区域高度上限 200px。终止错误和工具错误使用同一组件。
- 不再仅凭“配额”/`RESOURCE_EXHAUSTED` 断言账号余额耗尽。明确账单/余额证据才显示账户限制；429/频率/并发/用量限制单列。跨 realm WebKit `QuotaExceededError` 的身份在控制器脱敏后保留，scoped 服务保存字符串原文与小型分类，新的回合清空旧分类。文案不再直接要求充值。

## 已确认的存储压力

只读统计当时正式应用的 WebKit localStorage：18 项合计 5,106,240 字节，距 5MiB 仅 136,640 字节。三大 Agent 项合计约 2.66MB；14 个会话、116 个条目的历史约 393,114 JSON 字符，而幂等指纹又重复保存约 501,527 字符。一次待审批的 160,797 字符 SDK 恢复快照同时存在两个恢复源。

原生日志未记录本次 JS 终止异常或上游余额错误，不能唯一判定截图的具体触发点；但本地存储错误丢失身份再被误判到账单的代码路径已复现。预算中的付费预留仍在持久化失败时拒绝执行，不用放宽付费保护来掩盖问题。

修复：

1. 新幂等记录保存 SHA-256 摘要，不再复制整段 transaction。旧指纹仍能识别并阻止重复执行，重放时升级。
2. 会话、运行态与审批记录使用无损 gzip 压缩的新版本存储键。旧 JSON 可读；必须先写入新记录并读回验证成功，才移除旧字节。失败时保留旧数据，不清空对话。读取验证长度上限和 CRC，并缓存解码结果。
3. 只读内存测量真实三大记录：UTF-16 存储体积 2,661,430 → 571,740 字节，减少 2,089,690；逐字还原一致。压缩约 25ms，首次解码与校验约 24ms，后续未变记录复用缓存。没有将压缩结果写入用户数据库。

新存储格式不会让旧版本改写新压缩记录；降级旧包时旧版无法显示新格式的 Agent 历史，升级回新包可读取。完全没有临时写入余量时迁移会保留旧数据并退回原有保护，不承诺任意无限会话都能留在 localStorage。压缩不改变模型上下文、工具记录或生成任务，也不等于自动摘要。

## 视角与键位

舞台左栏新增手形「旋转视角」：左拖只环绕视角，从对象上开始也不会选中或移动对象、绘制选框或插入路径点。Shift/右键拖动平移，滚轮缩放。默认 B 切换、V 回选择、Esc 按现有层级退出；B/V 均接入舞台改键与提示。浏览器实际拖动验证视图改变且对象数据不变，B 改 K 后按钮提示/按键同步，Escape 回选择；真实 Three 场景测试也检查相机位置变化且对象回调未执行。

目前并非全软件所有按键可自定义：舞台提供编辑按钮的动作键可改，全局设置主要是画布拖动/滚轮/移动习惯；部分画布、时间轴、自由运镜按键仍固定。已在使用文档明确说明。

## 建模能力说明

手动与 Agent 可以组合基础体，调整位置、缩放、旋转、颜色搭新场景。复杂资产可导入 GLB/glTF，或在界面通过已接入的图生 3D 渠道生成；深度浮雕另有单图空间效果路径。当前没有自由网格/拓扑建模，也没有舞台 Agent 直接提交图生 3D 的工具。此轮没有冒称实现该能力或额外加入未经设计的新几何执行接口。
