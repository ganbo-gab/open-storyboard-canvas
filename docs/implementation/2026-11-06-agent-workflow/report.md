## 千节点 Chromium 补充观察：旧夹具边类型错误

**后续只读审查发现这份旧夹具使用 `type: 'disconnectable'`，产品实际注册的是 `disconnectableEdge`。因此它测到的是 ReactFlow 回退边，不能作为完整产品边渲染栈或 macOS 软件千节点通过的证据。** 下列数字保留用于追溯，只支持该节点/基础连线合成场景的观察；自定义基础线、命中线、动态高亮和路由开销未由这些数字覆盖。

这组数据与上一轮真实“火”副本的 WKWebView 实验分开。独立 Chromium/Chrome DevTools、生产构建，1440×900、DPR 2；夹具声明 1000 节点、1000 条边、350 张独立 512×320 PNG，其中 20 个导演台节点。10% 时实际挂载 1000 节点/1000 个边 wrapper/350 图片；60% 为 40 节点/80 个边 wrapper，100% 为 15 节点/30 个边 wrapper。这里的 wrapper 数量不代表产品自定义边数量。未打开三维舞台。媒体已解码，样本期间缩略图 heavyActive/heavyQueued/failures 均为 0。

同一旧夹具 A/B/A：基线全图平移 P50 约 50–66 ms、P95 约 67 ms；只为远景节点启用 `will-change: transform` 后，早期两次候选 P50 约 16.7 ms、P95 约 17.6 ms；撤回改动再次约 65.9/66.8 ms。去边、去图片或去透明 handle 的控制没有同等改善，只支持这份回退边夹具的远景重绘判断，不能延伸到完整产品边栈。标记仅跨 0.4 阈值时变更；恰好 0.4 退出，卸载或迟到回调不残留。CSS 声明不证明 WebKit 实际创建或释放了相同数量的 GPU 层。

## 追加的真正 macOS Tauri 千节点验收

使用真正 Tauri release QA bundle（`com.ganbo-gab.storyboard-mac-perf1106`），保留 `isTauri`、原生 SQLite 和 WKWebView；仅注入夹具准备与测量入口。Mac 为 Apple M3 / 16GB / macOS 15.7.4，窗口内容 1440×937、DPR 2。新 identifier 隔离应用数据；Keychain 服务前缀仍固定，因此没有复制真实渠道、凭据或“火”项目。

夹具为 1000 节点、1000 条正确 `disconnectableEdge`、350 张独立 512×320 PNG，含 20 个导演台入口（未打开 3D）。10% 时实际确认 1000 节点、1000 条产品基础线和 350 张已解码图片；无缩略图重任务/失败。它是渲染压力图，存在循环与不适合实际执行的类型连接，不是完整可执行生成 DAG。

真实用户第一次约 4.64 秒拖动捕获 159 个可信移动事件，rAF P50 29ms / P95 56ms / 最大184ms，图和历史稳定。后续一次 CUA 大幅滚动将图移出视野，用户随后操作时挂载量为0，该组流畅数字已排除。CUA 单次 drag 只有一个移动事件，不能据此报告连续帧率。

原生包内固定输入重放发现两个产品问题：全景平移在边界反复裁剪、重建节点；缩放的渲染计时器只观察已应用的变换，长帧时会在滚轮输入仍继续期间误释放全图与低细节覆盖。源码现将平移/缩放共用生命周期，直接检查真实手势 owner；已全挂载的远景图保持到手势结束，先恢复裁剪再两帧释放低细节与合成。部分挂载和普通近景仍正常裁剪。连接按钮只隐藏不使用的装饰 dot，父 Handle 及命中区域保留。

节点/连线整层合成、隐藏默认透明交互路径、取消浮层模糊等对照没有稳定改善，没有写入产品。静态样式与数量不足以证明实际 GPU 层或显存占用。
