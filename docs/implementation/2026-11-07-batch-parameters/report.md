# 同渠道模型参数统一配置

日期：2026-11-07。用户希望若同渠道几个图片模型可共用同套画面规格，可以一次配置、批量应用。

## 操作流程

渠道设置的模型管理新增「统一配置」：选来源模型/模式，默认选中尺寸、比例、分辨率参数，可再选质量、数量等；搜索或勾选目标，预览字段前后差异，再一次应用到当前草稿。最后保存渠道生效。没有自动联动关系，每个目标后续可单独修改。

可选「同时使用来源默认值」，默认关闭。目标当前默认值在复制后的声明下仍有效则保留；否则采用来源有效默认或首个枚举值。未指定/null的可选默认保持省略语义。原始参数的类型、选项、尺寸映射、显示方式、数值范围等属于选中声明，可一起复用；未选参数、请求端点、鉴权、模型ID、素材槽位与能力声明不变。

应用完成可立即撤销本次应用。后续有其他修改时撤销入口禁用，避免整份旧草稿覆盖新修改。预览期间profile变化也阻止应用，必须返回重新预览。

## 匹配边界

- 当前入口面向图片生成/图片编辑/视频生成，要求来源与目标操作相同；不同用途的目标禁选并解释原因。
- 同key需同type；枚举实际JSON结构必须相容，复合输出对象不能被字符串列表替换。
- 像素size与符号1K/2K等格式不兼容时阻止。不会自动猜size与resolution等字段重命名。
- 目标缺少参数时，仅其有效请求模板已引用param.key或其子字段才可新增；不会自动改请求模板。
- 显式模式只写该mode.params覆盖，不改model公共参数影响兄弟模式；旧模型多个用途共用参数时禁用批量写入，提示先拆成独立模式。
- 一次选中多个目标时全部重新校验，通过后对深拷贝原子应用。失败时不部分写入。应用后的目标声明互不共享可变对象。
- 这里检查配置结构，不证明上游每个模型接受同样选项；界面预览保留相应说明。不调用付费请求或凭据。
