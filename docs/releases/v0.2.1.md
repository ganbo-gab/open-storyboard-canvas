# v0.2.1：画布鼠标自定义与交互优化

这是基于 v0.2.0 的一次小版本优化，恢复并扩展鼠标自定义，修复抓手模式、双击创建、框选与菜单之间的操作冲突。

## 与 v0.2.0 相比

| 操作 | v0.2.0 | v0.2.1 |
| --- | --- | --- |
| 鼠标配置 | 主要可调整左拖和滚轮，右键与中键固定 | 左、中、右键的单击、双击、拖动共九项可独立设置，滚轮另选 |
| 常用习惯 | 需要适应固定组合 | 提供推荐、传统预设，随时逐项修改或恢复预设 |
| 抓手工具 | 会禁用节点的部分选择与编辑行为 | 只改变空白处左拖；节点仍可正常选择、移动和双击编辑 |
| 快速创建 | 部分手势组合下双击空白不响应 | 双击动作独立处理，可设置为快速创建；Tab 入口始终保留 |
| 旧设置 | 旧版六项鼠标配置在迁移或导入时被丢弃 | 兼容仍保留的旧配置与旧备份，新设置可保存、重开、导入导出 |

## 新增

- **九项鼠标自定义**：左键、中键、右键分别配置单击、双击和拖动。点击可选择“选择／清空选择、打开菜单、快速添加节点、适合屏幕、不执行操作”；拖动可选择“平移画布、框选节点、不执行操作”。
- **操作预设**：推荐预设为左拖空白平移、右拖框选、右单击菜单、中拖平移、左双击空白快建；传统预设为左拖框选、中拖平移。选择预设后仍可逐项修改。

## 优化

- 左键自定义针对画布空白处，节点选择、拖动、文字编辑与连线保持各自的交互；输入框、按钮、浮层和内嵌编辑器保留原有操作。
- 鼠标滚轮继续支持自动识别、缩放和平移。自动模式下鼠标滚轮缩放、触控板双指滚动平移；捏合与 ⌘/Ctrl＋滚轮可缩放。
- 按住 Space 临时平移，Shift 可追加框选或临时使用左拖空白框选。快捷帮助按实际鼠标映射显示。
- 拖动过程中只更新视口或局部选框，选框释放时才提交选择，平移结束时再保存视口，避免逐帧写入整个画布。

## 修复

- 修复抓手状态下难以选择其他节点、移动节点或编辑文字的问题。
- 修复双击空白创建失效、右键拖动结束误弹菜单，以及延迟单击菜单在切到其他控件后冒出的问题。
- 修复点击空白后多选或已选连线残留，避免后续删除误作用于旧选择。
- 修复水平／垂直拖出零面积选框、节点尺寸尚未就绪时可能误选整个画布的问题。
- 修复开始操作画布后焦点仍留在输入框、工具栏文字被误当成选中文本的问题。
- 修复旧鼠标配置的迁移与备份导入；无鼠标字段的旧备份不会重置当前配置，非法动作在导入前拒绝。

## 升级后怎么使用

打开 **设置 → 键位设置 → 操作预设**，选择 **“推荐：左拖平移 · 右拖框选”**，再点 **保存**。

从 v0.2.0 升级会保留原来的左拖、滚轮与右拖平移习惯，不会强制切换预设。仍保留 v0.1.27 六项配置的用户，以及旧版备份，可以迁移原设置；已经被 v0.2.0 覆盖丢失的自定义值无法自动重建，需要旧备份或重新设置。

## 安装包与验证范围

- Windows x64：`open-storyboard-canvas_0.2.1_x64-setup.exe`
- macOS Apple Silicon / Intel 通用包：`open-storyboard-canvas_0.2.1_universal.dmg`
- 两份安装包由本标签的 GitHub Actions 构建，随附 `SHA256SUMS.txt`。

实现阶段完整前端回归 **345 个文件／3159 项通过**，TypeScript 与生产构建通过；独立浏览器验证了九项设置界面、双击创建、左右键手势、抓手编辑、10% 缩放框选，以及中键自定义保存和刷新后保留。Mac arm64 预览包已通过编译、版本、架构、代码签名和镜像校验。

本轮未完成 Windows／Mac 原生 GUI 的全套手势复测，也未重新进行千节点性能测量；不以浏览器测试或构建成功代替这些结果。Mac 包沿用 ad-hoc 签名，未进行 Apple 公证。Agent 等实验功能的范围沿用 v0.2.0。
