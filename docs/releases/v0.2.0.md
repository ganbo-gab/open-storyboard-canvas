# v0.2.0：底层架构重构与创作工作流升级

本次从 v0.1.27 升级到 v0.2.0，将模型接入、生成工作台、资产、节点画布与舞台助手整理为更连贯的创作流程，并集中重构底层模块，修复输入、引用、任务恢复、浮层与大画布交互问题。画布优化使用跨平台共享代码，本轮性能数据来自 Mac 原生测量。

**Agent 与 AI 舞台编排仍处于实验阶段。** 本次包含协议兼容、长任务恢复和实际界面修复，不代表所有模型、工具组合或项目都已无错误。请检查执行模式、工具回执和生成费用。

## 与 v0.1.27 相比

| 方面 | v0.1.27 已有能力 | v0.2.0 的变化 |
| --- | --- | --- |
| 底层架构 | 画布、供应商适配、节点 UI 和工具执行存在较多交叉与重复实现 | 按职责拆分画布引擎、菜单、输入区和工具；统一渠道协议、生成提交与恢复、凭据边界及素材持久化，增加共享校验和回归测试 |
| 生成与素材复用 | 画布内生图、生视频、分镜和结果管理 | 增加集中处理图片、视频、音频、文本的生成工作台；按会话保存，结果可追溯、编辑并送回画布 |
| 模型接入 | 多供应商、自定义中转接口、ComfyUI、即梦 CLI | 统一“我的渠道”和“模型广场”；先填连接信息，再获取/手填模型，逐项确认类别、协议、模式和参数 |
| Agent | 画布 Agent、会话历史、审批与任务查询 | 首页、画布、舞台三个作用域；三种执行模式、询问卡、失败续接、上下文用量和更完整的协议兼容 |
| 输入与画布工具 | 提示词库、预设、摄像机、图片功能、标签组 | 共享富文本输入、可编辑预设正文、`@`/`/`、引用移除与编号同步；摄像机独立弹窗；工具栏可自定义 |
| 资产 | 媒体和生成结果管理、画布图片工具 | 资产库与画布共用内容编辑入口；编辑保存副本并保留来源，图片支持裁剪、标注、旋转和翻转 |
| 导演台与预演 | 已有三维构图、人物/镜头路径、动作、时间轴和导出 | 改进对象隐藏/锁定、多选、路线与机位编辑、四视图回流；舞台 Agent 可组合场景并编排预演 |
| ComfyUI | 已有连接、工作流导入、参考图、结果下载和任务恢复 | 完善多工作流、依赖预检与恢复；可让 AI 分析结构、建议输入/输出绑定，再审阅应用 |
| 大画布与桌面窗口 | 已有几何索引、裁剪、缓存和桌面交互 | 在两端共享的画布引擎中增加可回退的 GPU 连线缓存，Mac 原生场景已测；修复窗口控制、浮层位置和面板尺寸调节 |

ComfyUI、预演台、全景、画布 Agent、摄像机和提示词预设并非本版首次加入；上表区分已有能力与本次变化。[查看完整代码差异](https://github.com/ganbo-gab/open-storyboard-canvas/compare/v0.1.27...v0.2.0)。

## 新增

- **生成工作台**：集中选择图片、视频、音频和文本模型，按会话管理创作记录；支持素材引用、粘贴/拖入参考图、展开编辑、多结果查看、下载和发送到画布。
- **统一渠道与模型广场**：区分单模型、同类多模型和跨类别渠道。接入时先填 URL/API Key，再获取或手填模型 ID，勾选接入项并校正类型、请求协议和高级能力；模板模型名作为帮助示例，不自动接入过时模型。
- **可编辑的参数展示**：渠道可配置名称、选项、默认值、顺序和控件样式，并预览工作台效果。支持模型间选择性统一配置；尺寸可按原像素值或“分辨率 + 比例”展示，发送时保留实际接口值。
- **首页与舞台助手**：首页助手可整理创作方案、检索素材、准备画布与工作台任务；舞台助手可组合基础形体、人物和道具，安排走位、动作、机位与时间轴，结果继续保留为可编辑对象和轨道。
- **资产内容编辑**：图片与文本可在资产库/查看器编辑；音视频复用本地媒体工具。保存为新资产，保留原件和来源；画布图片编辑后生成衍生节点与来源连线。
- **AI 辅助配置**：可分析公开接口文档生成渠道/自定义图床草稿，或分析 ComfyUI 工作流建议绑定。保存与执行分开，配置分析不会自动上传素材或运行工作流。

## 优化

- **底层架构重构与代码规范化**：拆分画布交互、菜单、工具栏、输入区和生成模块；整理统一渠道协议、参数声明、凭据访问、任务状态与素材持久化路径。UI 与 Agent 复用图编辑和生成服务，减少多套实现产生的行为差异；通过类型约束、边界校验与回归测试提高后续维护的可追溯性。此轮是已有代码的大规模整理，舞台等历史大模块仍在继续拆分，不等于技术债或未知问题已经清零。
  例如，主画布组件 `Canvas.tsx` 从 v0.1.27 的约 4,396 行整理为 343 行的组合入口，交互引擎、工具栏和菜单移入各自模块；行数减少是职责拆分的结果，功能仍由共享模块承担。
- **输入更直接**：预设与收藏提示词可以追加或替换为输入框中的可编辑正文；`/` 搜索预设与图片功能，`@` 选择已连接素材。多张参考图时先明确操作对象，再调整提示词并生成。分镜输入写入当前镜头。
- **摄像机控制独立显示**：机身、镜头、焦距、光圈及本机预设使用可调大小的独立弹窗，不随画布缩放。开启后在生成时追加摄影提示词；它不是模型物理相机参数的通用控制接口。
- **界面布局与浮层**：左侧创作入口分组，节点工具栏保留少量常用项，其余进入“更多”；常驻数量、项目和顺序可自定义。短菜单互斥并支持点外部/Esc 关闭，复杂编辑窗明确关闭；侧栏与适用面板可拖动调宽、记忆尺寸或锁定。
- **三个内置 Agent 的执行链**：支持“请求确认 / 辅助执行 / 完全执行”。缺少模型或必要参数时询问；审批恢复保留所选模型、执行模式与任务偏好。同一会话禁止并发推进，重复审批不重复执行同一操作。
- **协议与长任务**：适配 Chat Completions、Responses、Anthropic Messages、Gemini 的工具结果配对。明确临时错误且尚未输出时最多重连三次；不盲目重放部分输出或受理情况不明的请求。每回合最多 96 次工具调用、30 分钟，达到限制后停止并保留已完成结果。
- **会话与知识**：失败后保留会话、工具回执及未发送草稿，支持继续未完成部分；上下文统计区分上游用量与本地估算。知识库可使用任意本地 Markdown 文件夹，Obsidian 为可选来源；媒体仍由资产库管理，跨库去重尚未实现。
- **任务可追溯**：工作台、节点、历史与日志显示当次保留的提示词、模型、参数、原任务 ID、结果与错误，不用当前配置覆盖旧记录。凭据暂停、查询未知、结果缺失与真正运行中的任务分开；连续六小时无可观察进展会暂停本地等待，供人工核对原任务。
- **舞台编辑**：完善隐藏/锁定、多选、路线时长与闭合、机位跟踪/定点/自由旋转、时间轴和指定时刻取景；单张与四视图可回流画布并保留来源连线。
- **跨平台画布优化（Mac 原生实测）**：保留 React Flow、可见区域裁剪与历史结构，普通连线增加有条件启用的 GPU 矢量缓存，不支持的样式或设备回退 SVG。在 M3/16GB、1000 节点/1000 条连线/350 张图片的隔离原生样本中，连续缩放 rAF P95 从约 505–758ms 降至 42–51ms；10% 首次平移仍有长帧。rAF 间隔不等于呈现 FPS，不承诺千节点恒定 60fps 或任意项目零卡顿。

## 修复

- 修复 Agent 图片粘贴变成文件路径、发送后附件不可见、输入残留及部分模型工具续聊报错；区分本地存储、限流、鉴权与账单错误，保留可展开的脱敏详情。
- 修复 macOS 凭据读取在提交、查询和下载阶段反复触发授权的问题；成功读取使用进程内缓存，拒绝后暂停，只有明确重新授权才重试相关访问。
- 修复部分中转接口已经返回结果、界面却继续等待，以及历史查询解析过窄、恢复入口和当次提交信息不一致的问题；恢复继续使用原任务句柄，不自动重新生成。
- 修复已暂停或长期无进展的旧任务一直显示“进行中”、持续计秒的问题；暂停不等于上游失败，也不会丢弃已经在途的成功返回。
- 修复画布连接点偏移、反向拖线、缩放后的菜单位置和层级冲突；弹窗中的方向键、Space 与点击不会再误操作底层节点。
- 引用缩略图提供独立 X，只断开当前节点的相关入边，不删除源素材或其他下游；同步清理槽位与 `@` 编号，保留未提交草稿。标签组/多帧的一根连线涉及多项引用时，先确认影响范围；分镜各镜头同步更新，一次图编辑一次撤销。
- 节点复制写入系统剪贴板，快捷键和右键使用最新复制内容；修复旧内存副本抢占、空白处粘贴覆盖选中素材、粘贴落点及输入区展开后视口偏移。节点包在写图前校验关键数据，普通混合文字不因包含媒体 URL 被丢弃。
- 修复旧摄像机预设编号不匹配、删空后默认预设复活、保存失败却显示成功；未知或损坏数据保留，不静默覆盖。
- 修复 Windows 知识库保存附件、回收与恢复时的目录共享冲突；文件操作统一使用目录句柄，保留防路径越界、链接替换与同名覆盖保护。
- 修复 Mac 窗口全屏、放大/还原及标题栏双击；完善 Windows 窗口按钮和状态同步逻辑。Windows 实际桌面行为的验证范围见下文。

## 升级前后需要留意

1. **先备份项目与设置。** 两类备份用途不同；设置备份不包含密钥明文。更换设备后需重新配置/授权凭据，本机素材也需一并迁移。节点剪贴板中的本机路径不等于已复制素材文件，不建议直接在迁移后的真实数据上降级到旧版。
2. **检查迁移后的渠道。** 旧 HTTP 供应商配置迁入统一渠道，无法等价迁移的字段会列出提示；请核对模型、模式、参数、引用槽位和请求预览。凭据存储与普通配置分开，迁移失败或锁定时先处理可见状态，不要靠删除全部渠道或清空钥匙串解决。模型能力建议不代表中转站已实测支持。
3. **Mac 钥匙串可能重新询问。** 首次使用凭据、明确重新授权或更新签名身份后，系统可能要求访问登录钥匙串。核对请求者是本应用后，在 macOS 系统弹窗输入钥匙串密码；信任该版本时可选“始终允许”。密码不要填进 API Key 栏。拒绝后使用应用恢复入口重新授权，再查询原任务。
4. **旧音频模型功能已移除。** 独立豆包 TTS、VoxCPM 适配器及对应设置退役，音频统一通过渠道接入；已有音频素材和历史保留，旧模型不会自动替换为其他收费渠道。直接返回二进制音频的任意 TTS 接口仍需专门适配。
5. **旧内置图床已停用。** 移除 PiXhost 等内置上传适配和旧登录换 token 流程，保留自定义上传 URL、文件字段、请求头及结果路径。旧/导入图床配置保持禁用，需要自行核对并启用；上传参考素材仍须明确确认。
6. **“查询/恢复”与“再次生成”不同。** 已受理任务优先查询原任务；远程地址过期、原任务/本地资产已删除，或旧版从未保存的返回内容无法凭空找回。图撤销不会撤销已经提交的付费请求、下载或知识库文件写入。

## 安装包与验证范围

本版由仓库现有 GitHub Actions 构建并上传安装包；请在构建完成后查看该 Release 的附件，源码压缩包不含可直接运行的桌面应用。

| 平台 | 安装包 | 已有验证与限制 |
| --- | --- | --- |
| Windows x64 | `open-storyboard-canvas_0.2.0_x64-setup.exe` | 跨平台逻辑、路径与模拟窗口事件有自动化回归；本轮没有 Windows 实机 GUI、Explorer 剪贴板、Snap、多显示器或 DPI 验收。CI 构建成功不能替代实机交互验证。缺少 WebView2 时需安装其运行时。 |
| macOS Universal | `open-storyboard-canvas_0.2.0_universal.dmg` | CI 构建 Apple Silicon + Intel；本轮本地原生交互以 Apple Silicon/WKWebView 为主，检查窗口控制、预设/摄像机、系统剪贴板、引用移除及指定画布场景。未进行 Intel Mac 实机 GUI 验收，也未覆盖所有来源的系统剪贴板和多显示器组合。 |

macOS 当前未提供 Apple Developer ID 公证；首次启动如被系统拦截，请通过系统“隐私与安全性”允许打开。构建/签名/镜像校验与实际 GUI 验证分别记录，不能将一个平台的结果当作另一个平台已通过。

发布前完整前端检查为 **344 文件 / 3132 项通过**，TypeScript、生产构建与 Rust 格式检查通过；Rust 测试、跨平台检查与安装包由本次 GitHub Actions 再验证。Agent 受控测试使用真实 SDK 配本地脚本传输，另有有限的真实 DeepSeek 工具续聊验证；不等于所有上游、全部工具、ComfyUI 工作流或舞台生成效果都已联调。

舞台编排仍以基础形体和现有/导入资产组合为主，不能保证百分百还原参考图或精细网格建模。V1 空间轨道仍是一对象一条轨道；没有新增无限上下文或无限后台续跑保证。部分图片功能是可编辑提示词模板，人脸框选定位、专门情绪调节等独立工具尚未完成。
