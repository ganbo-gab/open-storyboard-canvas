# v0.1.26

这是一次覆盖画布 Agent、生成可靠性、导演台、标签组、日志、性能和整体交互的大版本更新。

> **测试版提醒：画布 Agent 当前仍为 Beta/测试版。** 不同文本模型对结构化工具调用的支持和稳定性存在差异。涉及付费生成、配置修改和删除操作时，请检查执行模式、工具回执与供应商费用。

## 新增

- 新增画布 Agent（测试版）：可理解画布上下文、附件和用户意图，创建/查询/修改节点，提交并跟进图片与视频生成任务。
- Agent 支持手动/自动执行模式、上下文用量提示、工具调用回执、批准卡、会话历史、图片附件和可拉伸右侧面板；自动模式仅在删除节点时保留确认。
- 新增画布左侧日志入口，提供中文可读摘要、脱敏原文、筛选、诊断包和安全结果恢复。
- 新增统一标签组：可独立创建、选择图片/视频/文本成员、查看预览、连接生成节点，并把成员作为普通 `@` 引用使用。
- 新增表格批量导入提示词工作流。
- 导演台新增更多人物动作、自定义动作、场景录制和错误边界保护。
- 新增项目文件导入/导出与应用设置备份/恢复，并明确凭据包含范围和风险。
- 保留并继续支持全景生成/查看/导演台导入、提示词库与预设、摄像机控制、多角度与打光工具、多供应商配置、本地项目持久化及中英文界面。

## 优化

- 全面刷新 Agent 对话布局、模型/附件/模式选择、工具折叠、审批队列、IME 输入、状态反馈和明暗主题可读性。
- 生成任务提交后由 Agent 进行有上限的只读状态跟进，显示真实生成进度；完成后可定位生成框和最终结果。
- 大画布引入几何索引、窄状态订阅和缓存，减少智能连线、引用解析和频繁交互中的重复计算。
- 优化新节点与生成结果的位置选择，优先使用附近较大的空白区域并保持输入/结果视觉关联。
- Dreamina（即梦）CLI 更新为新的任务句柄与轮询契约，保留 `submit_id`，支持重复的安全结果查询。
- 自定义供应商结果获取支持本机代理、受控重试、网络诊断、同源鉴权和结果物化。
- 更新 README，重新整理下载、功能、配置、隐私、开发和贡献说明，并加入 TorchAI 友情赞助。

## 修复

- 修复 macOS WebKit 缺少 `ReadableStream` 异步迭代器时，Agent 回复只出现在历史记录、当前对话不显示的问题。
- 修复 WebKit localStorage 达到约 5 MiB 后历史空白或误报供应商配额的问题，并压缩终态恢复数据。
- 修复多轮对话中参数、`默认`、`继续`或“生成好了吗”等追问丢失画布工具的问题。
- 修复部分 OpenAI 兼容渠道把 Gemini 模型名误判为原生 Gemini 协议的问题。
- 修复 Agent 生成节点缺少安全位置提示、猜测节点类型或字段、伪造节点 ID，以及反复无效调用消耗额度的问题。
- 修复生成图片已经完成但旧历史结果仍让 Agent 持续轮询的问题；当前任务只跟踪最新生成批次。
- 修复明确配额耗尽仍立即重试、提供同模型自诊断或快速点击产生并发 Agent 回合的问题。
- 修复 Dreamina `job not found` 丢失上游任务句柄、日志缺失和无法重新获取结果的问题。
- 修复标签组右侧连接点不可用、成员引用向提示词注入标签组说明，以及旧标签/标签组项目兼容问题。
- 修复导演台偶发渲染异常拖垮整个画布、浅色模式错误文字对比不足及多处交互状态不清晰的问题。

## 安装说明

- Windows 下载 `open-storyboard-canvas_0.1.26_x64-setup.exe`。
- macOS 下载 `open-storyboard-canvas_0.1.26_universal.dmg`。
- macOS 安装包暂未签名和公证，首次打开时可能需要在“系统设置 → 隐私与安全性”中手动允许。
