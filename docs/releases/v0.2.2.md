# v0.2.2：模型配置一致性、凭据恢复与画布输入优化

这是基于 v0.2.1 的一次修复与体验优化更新。重点解决“明明选了一个模型，Agent 和诊断却说另一个”“生成 16:9 时等待节点显示 1:1”“数量改了不生效”以及闲置后凭据被错误锁定的问题。

## 与 v0.2.1 相比

| 项目 | v0.2.1 中的问题 | v0.2.2 的行为 |
| --- | --- | --- |
| 模型与参数 | 新节点残留 KIE、2K 等旧默认字段，Agent 和诊断可能误读 | 新节点不再预填这些旧默认值；当前配置、请求、查询与诊断统一读取有效配置 |
| 等待图片 | 选择 16:9，等待结果节点却默认显示 1:1 | 等待节点按本次提交参数显示比例和尺寸；1024×576 显示为 16:9 |
| 生成数量 | 参数面板的数量被右侧默认 ×1 覆盖 | 两处同步；只有提交模板真正使用数量参数时才作为上游原生批量 |
| 输入栏 | 长模型名可能挤走数量按钮 | 长文字省略，摄像机、数量与发送保持同一行；完整模型名可悬停查看 |
| 凭据恢复 | 已成功读取的凭据闲置 15 分钟后被应用误锁，部分临时故障一直卡到重启 | 移除应用人为过期锁定，临时存储故障可恢复，并区分缺失、拒绝和暂不可用 |
| 无效模型 | 某些旧路径会回退 KIE 或首个供应商 | 已选模型失效时要求重新选择；无法解析供应商的原生请求在读取凭据前停止 |

## 修复与优化

- 图片、分镜与工具面板不再混入另一份旧模型的尺寸和参数。像素尺寸、比例和渠道声明的默认值按实际配置解析；未声明的参数不凭空补成 2K。
- 画布 Agent 查询、生成审批概要、任务详情和历史采集采用一致的配置解释。历史以当次请求、任务和冻结快照为依据，不用当前配置改写以前的生成事实。
- 新开 Agent 会话可避免旧对话中的错误解释继续影响回答；更新不会自动改写已经保存的聊天文字。Agent 仍在测试迭代，不能保证所有模型、工具组合都正确。
- 旧项目兼容数据保留。KIE 等显式旧供应商适配器仍可用于兼容，移除的是新节点强塞的默认值和隐式回退，并非删除用户接入的渠道。
- 清理约 1360 行确认无消费者的旧参数界面、供应商设置页面、浮层、样式和辅助函数。仍在使用的渠道管理、多角度、打光等功能保留；这不代表所有技术债与未知问题已经消失。
- Windows 登录会话暂不可用、macOS 部分钥匙串暂不可用错误不再一律显示为“未授权”。已拒绝的访问仍会停止；恢复只查询原任务，不自动重复提交生成。

## Mac 钥匙串：本版仍需说明的限制

**本次 Mac 包仍使用 ad-hoc 临时签名，尚未配置固定签名身份，也未进行 Apple 公证。** 这是维护者明确选择暂缓固定签名后的发行方式，不是自动忽略签名检查。

从 v0.2.0 起，Key 从普通配置迁入系统凭据存储。项目与渠道数据保留，和钥匙串是否认可新程序，是两件事：临时签名的代码身份会随构建变化，**更新后每条已保存凭据首次使用都可能分别要求确认**。信任并确认请求者为本应用后，可在 macOS 系统窗口选择“始终允许”；密码只输入系统窗口，不要填到 API Key 栏或反馈到 Issue。

本版修复了应用自身的 15 分钟误锁与临时故障永久阻断，**没有解决临时签名跨版本授权继承，也不承诺永久零弹窗**。Windows 不使用这套 Mac 签名访问规则，但仍可能遇到系统凭据存储或登录会话故障。无需为了升级清空渠道、项目或钥匙串。

后续若配置固定签名，首次切换身份时旧条目仍可能需要确认，再通过同一稳定身份的后续版本验证授权延续。实现与限制见[签名说明](https://github.com/ganbo-gab/open-storyboard-canvas/blob/v0.2.2/docs/release/macos-signing.md)。

## 升级与安装包

完全退出旧版后安装替换，可继续使用原项目、渠道和已保存的 Key。

- Windows x64：`open-storyboard-canvas_0.2.2_x64-setup.exe`
- macOS Apple Silicon / Intel 通用包：`open-storyboard-canvas_0.2.2_universal.dmg`
- 校验文件：`SHA256SUMS.txt`

建议验收：在原项目中新开 Agent 会话，询问生成节点使用的模型；再核对模型选择、数量、请求预览、等待比例和任务详情是否一致。若仍有异常，请提供版本、操作步骤与脱敏截图，不需要提供密钥。

## 验证范围

实现阶段完整前端回归 **350 个文件、3208 项通过**；TypeScript、生产构建通过。Mac 原生 AI/路由定向回归 **39 项通过**，此前同一改动集的凭据隔离回归 **29 项通过**。独立浏览器验证了实际点击生成后的等待比例、Agent 使用的 `canvas.query`、请求预览、长名称和单行布局；Mac arm64 验收包经编译、签名、版本、架构和镜像检查后交用户试用。

本 Release 的两个安装包由同一提交的 GitHub Actions 完整检查和构建生成。构建/自动化回归不等于所有 Windows/Mac 原生 GUI 或真实供应商均已实测；本轮没有新增真实付费生成测试，也没有完成固定签名的跨版本系统授权验收。
