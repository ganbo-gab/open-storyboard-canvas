## 新增

- 新增 ComfyUI 独立设置入口，支持本地与自部署云端服务、基础文生图/参考图重绘模板，以及 API Format 工作流导入、参考图上传、结果下载和已有任务恢复。
- 新增 MiniMax H3 官方视频供应商，支持文生视频、首帧、尾帧、首尾帧及多模态参考；提供 4–15 秒、768P/2K，默认 5 秒、768P。
- 新增 ComfyUI 本地 H3 工作流入口，自动识别提示词、采样种子、画幅与帧数。需先在 ComfyUI 部署模型并跑通完整工作流；Comfy Partner API 节点的凭据注入暂不支持。
- 导演台新增独立预演工作区，提供人物/镜头路径编辑、动作片段、跟拍与运镜、时间轴缩放和吸附、播放速度及视频导出，并扩充角色与动作选择。

## 优化

- 重排预演台的左侧工具、中央场景、右侧对象属性和底部时间轴，支持收起侧栏；按钮增加明确名称、悬停说明、焦点和选中反馈。
- 优化画布 Agent 的对话、历史、任务导航与侧栏布局，保留任务查询、工具审批和项目隔离。
- 完善中转站图片请求契约：可独立配置文生图/图生图端点、JSON/multipart/form-urlencoded、图片单个/数组/重复字段、响应路径及异步轮询，并提供脱敏预览。
- ComfyUI 视频按工作流实际绑定开放输入和参数，未绑定项显示“由工作流决定”；H3 使用自身的画幅和帧数规则。
- 补充 ComfyUI、MiniMax H3、预演台和中转兼容使用说明。

## 修复

- 修复部分上游响应错误被当作请求参数错误而重复提交生成的问题，降低重复计费风险；网络结果不明确时不自动重发。
- 修复界面先显示生成成功、数据库随后保存的状态顺序；存储失败保留安全恢复信息，已确认失败的任务不再误显示可恢复。
- 修复中文“响应解析失败”被误报为 DNS 错误，以及视频参考素材超出上限后被静默截断的问题。
- 修复 ComfyUI 视频时长选择不生效、参考图能力误报、空参考图漏检、Advanced sampler 种子识别和 H3 请求预览尺寸错误。
- 修复编辑图片契约首个图片字段时丢失后续字段，以及仅配置视频供应商时仍提示未配置供应商的问题。
- 修复 Agent 审批恢复遇到配额、限流或本地存储问题后，仍提供无效的同模型自诊断入口。
- 修复预演台镜头路径不可见、选择状态错位、Esc 误退出、运镜模板丢失跟拍对象、密集关键帧重叠和快速拖动未提交等问题。
- 修复预演视频录制时长明显短于项目时长，以及浏览器环境导演台保存调用桌面接口的问题。
- 修复已配置 Agnes 图片供应商未被正确识别的问题。
