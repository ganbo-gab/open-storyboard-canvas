# 导演台与预演台

打开导演台时默认处于「导演台」模式。右上角「保存工程」左侧可切换到「预演台」。人物、场景与预演轨道保存在同一个工程里。

## 预演台的布局

- 左侧：选择、旋转视角、移动、旋转、缩放、绘制、标记、人物、模型库、摄影机、动作库、灯光和教程。
- 中央：场景视窗。右上角切换「看路线」「看成片」，以及显示路线、框选全部、复位和聚焦。
- 右侧：场景对象与当前对象/关键帧的属性。顶部「场景与属性」按钮可以收起右侧栏，扩大场景。
- 底部：播放控制、时间刻度和轨道。拖动顶部细把手可改变时间轴高度。

按钮直接显示短名称，悬停或键盘聚焦显示用途说明。不可用按钮会说明需要先选择什么。

点左侧手形的「旋转视角」，即可用鼠标左键拖动环绕查看，包括从对象上开始拖动；不会移动对象或绘制选框。右键或 Shift 拖动平移，滚轮缩放。默认 B 切换此工具，V 回到选择，Esc 退出旋转工具；在舞台「快捷键与教程」中可以修改 B/V 和其他提供编辑按钮的动作键。

当前不是所有键位都能自定义：舞台动作键支持改键，但鼠标修饰键、部分时间轴/自由运镜按键和主画布快捷键仍有固定绑定；全局「键位设置」主要控制画布拖动、滚轮与移动习惯。

## 创建模型的范围

可以组合已有基础形体、调整位置、尺寸、旋转与颜色来搭建新场景，手动操作与舞台 Agent 都可使用这些对象命令。复杂资产可导入 GLB/glTF，或在「读图建场景」的图生 3D 流程选择已接入的模型渠道。深度浮雕用于单图的空间效果，不能等同于完整多面模型。

当前没有 Blender 式的顶点、面、拓扑编辑，也没有让舞台 Agent 任意编写和执行几何代码的接口。舞台 Agent 可组合对象和编排场景，尚未直接接通图生 3D 的付费提交工具；不会把拼装场景宣称为任意精细网格生成。

## 做一段本地预演

1. 点左侧「人物」添加角色，或在右侧对象列表中选中已有角色。
2. 点「绘制」，按住鼠标在地面拖动后松开；或点「标记」，逐点点击地面，再点「完成轨迹」。新路径默认占至多 4 秒，会出现在底部并自动选中。
3. 拖动路径片段改变开始时间，拖动两端改变时长。选中编号关键帧后，可在右侧修改时间、XYZ 位置与朝向。密集关键帧显示为细标记；点击轨道名下面的「帧数·放大」可展开，右侧下拉列表也能选中每一帧。
4. 点「动作库」选择本地动作。应用后返回预演台，右侧显示该动作参数，时间轴显示动作名称。动作持续到下一个动作关键帧或工程结束。
5. 点「摄影机」选择运镜模板，也可选中摄影机后在地面绘制镜头路径。「看路线」显示摄影机路径的地面投影，拖动路径点保留镜头高度；高度在右侧位置 Y 中编辑。已选人物有路径时，场景右上方提供「跟拍人物」。
6. 点播放，使用「看路线」观察运动，使用「看成片」检查镜头构图。摄影机有至少两个关键帧后，点顶部「录制」，保存视频或添加到画布。

## 时间轴操作

- 拖动刻度尺：定位播放时间。
- 左右方向键：移动 1 帧；按住 Shift 移动 10 帧（时间轴编辑使用 24 fps）。
- 聚焦关键帧或路径片段后，左右方向键微调其时间。
- 「吸附」按帧对齐；拖动时按住 Alt 临时关闭。
- 「+」「−」「适应」调整时间轴显示比例；放大后可横向滚动。
- 预览速度支持 0.25×–2×，导出仍使用原始工程时长。
- Esc 取消当前路径绘制或拖动，取消拖动不会保存中间位置。

「自由运镜」在摄影机模板面板内，用于手动摆镜头：WASD 移动、鼠标转向、Enter 记录当前机位、F 锁定画面中央的人物、Esc 退出。

切回「导演台」会停止播放并恢复静态场景编辑；再次进入「预演台」可继续编辑已保存的轨道。当前保持 V1 数据：一条对象轨道作为一段路径整体编辑。本地动作、镜头轨道和视频录制可直接使用；外部文生动作、视频动作捕捉、自动空间重建未接入。
