SHOT 01 · 24mm 推轨进入

生成工作台：先试出满意的底图与素材

图片、视频、音频和文本对话都在同一个工作台里。输入区打 @ 引用素材，打 / 选预设；每次提交都记下当时的模型、参数和原任务 ID，查旧结果不会误点重扣费。

  • 尺寸支持像素与“比例 + 分辨率”切换，底层仍按渠道真实值提交
  • 同一批多张结果可直接对比、下载、设为参考或送进画布
SHOT 02 · 35mm 水平横摇

无限节点画布：把零散结果接成工作流

把文本、参考图、生成、分镜、全景和导演台节点连起来持续迭代。独立摄像机弹窗可调机身、焦距和光圈，不随画布缩放；裁剪标注后存成新副本，保留原图和来源连线。

  • 鼠标左/中/右键共 9 项操作独立可配，提供左拖平移推荐预设
  • 大画布做过视口裁剪与矢量连线缓存，缩放拖动更跟手
SHOT 03 · 50mm 三维环绕

三维导演台与预演台：把机位和走位摆明白

在三维空间或全景背景里放人物、道具、灯光和摄影机，在地面直接画走位路线、在时间轴调关键帧。随时拍单张或四视图送回画布，也支持用实验性舞台 Agent 搭出可编辑草稿。

  • 摄影机支持跟随人物、看向固定点与自由旋转
  • 支持 GLB/glTF 导入、录制以及按渠道能力调用图生 3D
SHOT 04 · 85mm 焦点锁定

三端 Agent 与多模型渠道：可控、可查、不盲跑

首页、画布和舞台各自带一个懂当前上下文的助手，支持请求确认、辅助执行、完全执行三种权限。渠道同时管单模型、中转站、ComfyUI 和即梦 CLI，API Key 交给系统钥匙串独立保管。

  • 单回合 96 次调用 / 30 分钟保护，出错可续接，不乱重发付费任务
  • 支持挂载本地 Markdown / Obsidian 目录当项目知识库

03 — CORE CAPABILITIES

五大模块，全部按真实桌面源码整理

不夸大、不画饼，以下每一项能力都对应当前 v0.2.2 仓库里的实际功能。

01 · GENERATION WORKBENCH

生成工作台与历史追溯

图像、视频、音频和文本对话集中在同一工作台。按创作会话归档，支持 @ 引用素材与 / 预设；任务中心分开展示进行中与异常暂停项，查询原任务与再次生成严格隔离。

Multimodal Sessions Ratio + Resolution Original Task Polling
02 · INFINITE CANVAS

无限节点画布

文本、媒体、生成、分镜、全景与导演台节点自由连接；独立摄像机弹窗、9 项鼠标键位自定义，图片与音视频编辑均存衍生副本并保留来源连线。

React Flow Camera Modal 9-Way Mouse
03 · 3D DIRECTOR STUDIO

三维导演台与预演台

在 3D 场景或全景背景里摆人物、道具、灯光与机位，画路线调关键帧；拍单张或四视图直接送回画布，并支持实验性舞台 Agent 搭建可编辑草稿。

Three.js 4-View Capture GLB / glTF
04 · SCOPED AGENTS & KNOWLEDGE

首页 / 画布 / 舞台三端 Agent 与本地知识库

三个入口各自读取当前页面上下文，提供请求确认、辅助执行和完全执行三种模式；共享 96 次调用 / 30 分钟保护、失败续接与脱敏统计，不开放任意系统命令。可直接挂本地 Markdown / Obsidian 目录检索笔记。

Approval Cards 4 API Protocols Obsidian Compatible Sandboxed Tools
05 · CHANNELS & CREDENTIAL ISOLATION

单模型、综合中转站与 ComfyUI 统一接入

支持协议模板、让 AI 读接口文档生成配置、或直接粘贴配置 JSON；免费拉取模型列表与计费试运行严格分开，支持批量“统一配置”、ComfyUI 多工作流 AI 绑定分析与 Dreamina（即梦）CLI。所有 API Key 单独保存在 macOS 系统钥匙串或 Windows 凭据管理器里。
